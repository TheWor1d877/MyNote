Lambda 是编译器生成的**非联合、非聚合的匿名仿函数类**。捕获列表中的变量作为该类的私有成员变量，`operator()` 是其成员函数。

### const 语义与修改规则

`operator()` **默认是 const 成员函数**，按值捕获的成员变量在体内只读：

```cpp
int x = 0, y = 0;
[x, y]() { y++; }        // ❌ const operator()，y 作为 const 成员不可改
[&x, &y]() { y++; }      // ✅ 引用捕获，const 仅限制引用本身，不限制所指对象
[x, y]() mutable { y++; }// ✅ mutable 将 operator() 变为非 const，可改副本
```

- `mutable` 只解除对**按值捕获副本**的修改限制，不影响外部原始变量。
- 引用捕获本身不受 const 约束，无需 mutable。
- **捕获时机**：按值捕获在 lambda **创建时**拷贝，不是调用时；后续外部变量变化不影响已捕获的值。
- **生命周期陷阱**：引用捕获绑定外部变量生命周期，lambda 异步执行或返回后外部变量销毁 → 悬垂引用（UB）。
- **对象大小**：= 所有按值捕获变量大小之和；引用捕获通常只占一个指针大小；无捕获 lambda 大小为 1（空类优化），且可隐式转换为函数指针。
- **类型唯一性**：每个 lambda 表达式生成独立匿名类类型，代码相同也不是同一类型，不能用具体类型声明（C++20 前只能用 `auto`）。
- **初始化捕获（C++14）**：支持 `[x = std::move(obj)]` 等表达式，实现移动捕获，避免不必要的拷贝。
- **泛型 lambda（C++14）**：参数可用 `auto`，等价于模板 `operator()`，每次调用实例化不同版本。
