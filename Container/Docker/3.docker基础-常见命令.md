## 部分常用命令
`docker pull` : 下载镜像
`docker images` ： 查看镜像
`docker rmi` ： 删除镜像
`docker build` : 创建镜像
`docker save` :保存镜像
`docker load` : 加载镜像
`docker push` : 推送镜像
`docker run` : 运行镜像（如果不存在，那就先拉取镜像）
<span style="color:rgb(221, 85, 85)">注意: 每次执行这个命令都会创建一个新容器</span>
	--name,-p,-e
`docker stop`:  停止容器的运行
`docker start` : 开始容器运行
`docker ps` ： 容器的运行状态
	加上-a参数现实的是所有的容器，如果不加，显示的是运行中的容器
`docker rm` : 删除容器
`docker logs`: 查看容器的运行状态
`docker exec` : 进入一个容器，然后可以查看容器的详细信息
