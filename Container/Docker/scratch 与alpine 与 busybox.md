scratch 是 Docker 提供的一个“虚拟空镜像”——它不包含任何文件、任何目录、任何程序，甚至没有 /bin/sh。scratch 的存在是为了让你能构建 “只有你的程序，别无他物” 的极致精简镜像。

Alpine Linux一个基于 musl libc 和 BusyBox 的轻量级 Linux 发行版。
特点：体积非常小（基础镜像仅 5 MB 左右），默认安装精简，注重安全（内核有补丁），且包管理工具 apk 使用方便。

如果可执行文件（exe）依赖外部 .so 动态库（shared libraries），那么它绝对不能在 scratch 镜像中运行。


| 特性 | **Scratch** | **BusyBox** | **Alpine** |
| :--- | :--- | :--- | :--- |
| **本质/构成** | **空空如也的“地基”** <br>是一个**空镜像**，不包含任何文件、目录或工具。 | **只有工具的“毛坯房”** <br>由**单一的 `busybox` 可执行文件** + 必要的软链接组成。 | **功能齐全的“精装房”** <br>完整的**迷你 Linux 发行版**，包含 `busybox`、包管理器 (`apk`)、C库 (`musl libc`) 等。 |
| **大小** | **0 MB** <br>从零开始，没有任何额外开销。 | **~1-5 MB** <br>极其小巧，提供了基本的操作命令。 | **~5-8 MB** <br>虽然体积稍大，但功能完备，足以作为通用应用的基础。 |
| **C 库** | **无** <br>无法提供C库支持。 | **可有可无** <br>可以**静态编译**脱离C库，也可以**动态链接**到 `glibc` 或 `musl`。 | **有 (musl libc)** <br>自带 `musl libc`，一个轻量、符合标准的C库。 |
| **包管理器** | **无** | **无** <br>无法直接安装新软件，扩展能力有限。 | **有 (`apk`)** <br>拥有自己的包管理器，可以方便地安装、更新和删除软件包。 |
| **内核** | **无** <br>所有容器都共用宿主机的内核，这一点三者相同。 | **共用宿主机内核** | **共用宿主机内核** |


-   **Scratch：追求极致的最小化**
    它就像一个空盒子，最适合用来运行**完全静态编译的二进制文件**（比如用 Golang 或 Rust 写的程序）。你的程序本身就是一个完整的“操作系统”，不需要任何外部依赖。

-   **BusyBox：轻量级调试和基础环境**
    当你需要一个微型 Linux 环境来执行一些基础命令，或者作为构建其他镜像的中间层时，BusyBox 是绝佳选择。它体积小巧，但提供了你常用的 `ls`、`cat`、`sh` 等命令。

-   **Alpine：通用的迷你 Linux 发行版**
    这是**生产环境中最常用的选择之一**。它基于 `musl libc` 和 `busybox`，并在其基础上增加了安全更新和极其方便的 `apk` 包管理器。这意味着你可以在一个很小的镜像里，轻松地安装 Python、Nginx 等运行时环境。它平衡了体积和便利性，因此被广泛用作各类应用镜像的基础。
