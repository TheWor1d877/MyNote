## 网络

| 命令                        | 说明           |
| ------------------------- | ------------ |
| docker network create     | 创建一个网络       |
| docker network ls         | 查看一个网络       |
| docker network rm         | 删除指定网络       |
| docker network prune      | 清除未使用的网络     |
| docker network connect    | 使用指定容器连接某网络  |
| docker network disconnect | 使用指定容器离开某个网络 |
| docker network inspect    | 查看网络的详细信息    |

## 优点
- 这样操作之后就可以使用名称进行交互，而不是ip地址
- 同一网桥下面的ip地址才可以进行访问，否则不可
- Docker使用Linux桥接技术，在宿主机上创建一个虚拟网桥（如docker0），该网桥类似于一个虚拟的二层交换机。
- 当容器连接到同一个网桥时，它们处于同一个二层网络中，可以通过容器的内部IP地址直接通信。
- 如果容器连接到不同的网桥，它们会被隔离在不同的网络中，无法直接通过IP地址通信-
