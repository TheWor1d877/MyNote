## 案例：利用nginx部署静态资源
### 问题
```bash
root@c9998e1d889d:/usr/share/nginx/html# vim index.html
bash: vim: command not found
```
最小化的镜像环境，没有相关的不需要的命令，比如说vim
所以说需要<span style="color:rgb(221, 85, 85)">数据卷</span> 

### 数据卷介绍
- 数据卷是一个虚拟目录，是容器内目录与主句目录之间的映射桥梁
-  实现宿主机与容器中数据的双向绑定
创建在宿主机下面的:
`/var/lib/docker/volumes/`这个目录下
![[Pasted image 20250503165953.png]]

### 数据卷操作
#### 基本命令
- 创建数据卷
`docker volume create`
- 查看所有的数据卷
`docker volume ls`
- 删除指定的数据卷
`docker volume rm`
- 查看某个数据卷的详情
`docker volume inspect`
- 清除数据卷
`docker volume prune
- 帮助
使用`docker volume --help`查看数据

如果一个容器已经创建了，就不能再去挂载数据卷了

#### 完成数据卷的挂载
`docker run -d --name nginx -p 80:80 -v html:/usr/share/nginx/html nginx`
在docker run中使用-v参数，完成数据捐的挂载
- 当创建容器的时候，如果挂载的数据卷不存在，自动创建
也就是说create数据卷没必要自己使用
