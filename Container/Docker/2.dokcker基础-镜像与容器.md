使用docker安装应用的时候，docker回收站自动搜索并下载<span style="color:rgb(221, 85, 85)">镜像</span>，镜像包含了需要的环境，配置，系统函数库。
docker会在运行镜像的时候创建一个隔离环境，称作<span style="color:rgb(221, 85, 85)">容器</span>
镜像仓库：存储和管理镜像的平台，docker官方维护了一个仓库：dockerhub
hub.docker.com
应用之间不相互干扰

例如：部署MySQL
```bash
docker run -d\
--name mysql \
-p 3306:3306 \
-e TZ=Asia/Shanghai \
-e MYSQL_ROOT_PASSWORD=123 \
mysql
```
`-d`  后台运行
`--name` 取一个名字
`-p` 设置端口映射
docker的一个容器是与外界隔离的，外接访问不到容器的ip地址与端口

宿主机端口：容器内端口
`-e`：配置环境变量 => KEY=VALUE
