## DockerCompose
手动部署缺乏完整性，DockerCompose解决这个问题
DockerCompose 通过部署一个单独的docker-compose.yml文件，来定义一组相关联的应用容器，帮助我们实现多个相互关联的Docker容器的快速部署
![[Pasted image 20250504142549.png]]
这个文件与docker run有异曲同工之处
![[Pasted image 20250504143003.png]]
描述的都是一样的，只是语法不一样
#### 使用dockercompose进行部署
![[Pasted image 20250504144158.png]]
- 创建并启动这个容器
`docker compose -f 文件名 -p project名称  up  -d`
![[Pasted image 20250504144458.png]]

  - 停止容器
`docker compose down `

- dockercompose还能实现集群部署，实现负载均衡
