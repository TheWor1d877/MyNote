# 云原生面试题库（修订版）

面向 AI Infra 方向的云原生面试题库，覆盖容器与运行时、Kubernetes 核心、GPU 资源与调度、集群批调度与弹性扩缩，共 100 题；★ 标记为面试必会的 P0 题。

## 容器与运行时

1. ★ 从容器本质出发，解释 namespace 与 cgroup 分别解决了隔离和资源限制中的什么问题。
2. ★ 为什么容器不是轻量级虚拟机？容器共享内核带来的性能优势和安全代价分别是什么？
3. ★ 解释 runc、containerd、CRI-O、Docker 之间的关系，以及 Kubernetes 为什么最终通过 CRI 解耦运行时。
4. 什么是 OCI 镜像规范与 OCI 运行时规范？它们分别约束了哪一层？
5. 解释镜像分层与联合文件系统的原理，以及为什么镜像层设计会影响模型加载速度。
6. 什么是 Copy-on-Write？它在容器启动、模型文件读取和写时复制场景中的性能特征是什么？
7. 解释 cgroup v2 在 kubelet 中的落地差异：统一层级、cpu.weight 与 memory.qos 等接口变化，以及 cgroupfs 与 systemd 两种驱动对资源管理、观测与 eBPF 生态有什么影响？

12. ★ 解释 Deployment、StatefulSet、DaemonSet、Job、CronJob 的语义差异与适用场景。
13. 为什么有状态训练任务、分布式推理服务、日志采集组件通常选择不同的工作负载控制器？

17. 什么是 Ingress 与 Gateway API？它们和 Service 的边界在哪里？

## GPU 资源与调度

32. 什么是 GPU 算力切分与显存切分？只切分显存而不限制算力占用时，多个租户之间会互相造成什么影响？

34. 解释 NVIDIA MPS 的原理：它如何让多个进程共享同一 GPU 的 SM？相比时间片共享有什么优势？适合什么场景，又会引入哪些隔离与故障域问题？
35. 什么是 GPU 拓扑感知调度？NVLink、PCIe、NUMA 亲和性分别如何影响多卡训练与推理的通信性能？调度器应如何利用拓扑信息打分？
36. 解释 NUMA 感知调度在 Kubernetes 中的现状与挑战，尤其是多 GPU 多网卡场景。
37. 什么是 RuntimeClass？它如何支持 gVisor、Kata Containers、NVIDIA 容器运行时等不同运行时？
38. MIG 设备在 Kubernetes 中如何表示为扩展资源？一块 GPU 切分出的 MIG 实例如何通过 nvidia.com/mig-1g.5gb 这类资源名完成上报与分配？
39. ★ 解释 DRA（Dynamic Resource Allocation）与 NRI（Node Resource Interface）分别解决什么问题？相比 Device Plugin，它们在资源建模、分配灵活性与节点设备可观测性上补齐了哪些能力？
40. 如何基于 scheduling framework 编写自定义 GPU 打分插件？你会依据哪些信号（碎片率、拓扑亲和、剩余显存、任务类型）设计 Score 逻辑，又如何避免打分插件拖慢调度吞吐？
41. 什么是调度器 Profile？如何为在线推理与离线训练配置不同的过滤、打分与抢占策略？

82. etcd 的 compaction 与 defrag 为什么"定期做"也可能把集群做挂？压缩、碎片整理与空间配额告警的先后顺序该怎么排？

85. 取舍辩论：日志采集、服务网格与模型初始化各自适合 sidecar 还是进程内 SDK？为什么镜像一大，sidecar 的账就先爆？

88. 量级估算：3000 节点、每节点 30 个 Pod、1000 个 Service 的集群，iptables 模式下每条 Endpoint 变更触发的规则重写量级有多大？IPVS 从哪一步开始赚回优势？

90. 把所有工作负载的 Limit 都设成 Request 的两倍看起来"更安全"，为什么节点的资源压力驱逐反而更容易发生？
