# 性能工程面试题库（修订版）

覆盖性能分析方法论、基准测试、Profiling 工具与系统排查工具链的面试题，共 45 题，标注 ★ 的为面试必会 P0 题。

## 性能分析方法论

★1. 什么是性能工程中的“测量优先”原则？为什么凭直觉优化往往适得其反？
★2. 解释 USE 方法与 RED 方法，并说明它们分别适合排查哪类系统。
3. 如何系统化定位一个训练任务的瓶颈在 CPU、内存、I/O、网络还是 GPU？
4. 什么是 Amdahl 定律？它如何限制系统整体加速比。
5. 什么是 Universal Scalability Law？它比 Amdahl 定律多刻画了什么。
★6. 解释排队论中的 Little 定律，以及它如何用于推理网关容量估算。
★7. 什么是尾延迟？为什么 P99 比平均值更能反映用户体验。
★8. 解释尾延迟放大效应，一个请求经过多级服务时尾延迟如何累积。
9. 什么是抖动？如何区分 GC 抖动、调度抖动、网络抖动与存储抖动。

## 基准测试与负载建模

★10. 解释微基准测试的陷阱：预热、编译器优化、缓存效应、测量开销。
11. 什么是负载生成？如何设计贴近真实推理请求分布的压测。
★12. 解释闭环压测与开环压测的差异，以及它们分别适合什么场景。
★13. 什么是协调遗漏？为什么基于响应时间的压测可能低估系统压力。

## Profiling 工具

14. 解释 perf 的基本用法，如何用 perf top、perf record、perf report 定位热点。
★15. 什么是火焰图？on-CPU 火焰图与 off-CPU 火焰图分别揭示什么。
★16. 解释 eBPF 在性能分析中的优势，以及 bpftrace 的典型使用场景。
17. 什么是 ftrace 与 tracepoint？它们在内核延迟分析中的价值是什么。
18. 解释 strace、ltrace 的开销，以及何时不该用它们。

## GPU 与 AI 负载分析

19. 什么是 Nsight Systems？它如何展示 CPU、GPU、CUDA API 的时间线。
20. 什么是 Nsight Compute？它如何分析单个 kernel 的瓶颈类型。
21. 解释 PyTorch Profiler 的用法，以及它如何与 Nsight 互补。

## 生产性能工程

22. 什么是持续 profiling？它如何在生产环境中低开销采集性能数据。
23. 解释性能回归检测，如何把 benchmark 集成到 CI 中。
24. 什么是容量规划？如何根据 QPS、P99、GPU 利用率估算所需副本数。

## 系统排查工具链

★25. 解释 top、mpstat、vmstat 的关键指标：%sys、%soft、run queue 分别说明什么？读数异常时分别指向哪类问题？
★26. 如何用 free 的 available 字段与 major fault 定位内存压力与回收、换页问题？
★27. 解释 iostat 的 util、await、aqu-sz，以及它们与 IOPS、带宽的关系，如何判断磁盘是否打满？
★28. 如何用 ss 与 ethtool -S 观察重传、丢包与队列溢出计数？
★29. 如何用 /proc/interrupts 与 IRQ affinity 排查中断集中在单个 CPU 的问题？
★30. 如何用 pidstat 定位 DataLoader worker 的 CPU 与 I/O 占用异常？
★31. 黑盒决策树：一个训练任务突然变慢，你只有一台机器上的 shell，给出完整的排查顺序与每一步的判断依据。
★32. 什么是基准测试卫生？为什么需要多次运行取中位数、报告方差并锁定环境变量？

## 思考与取舍题

34. 把 P99 打下来可能损害 P50：构造一个"优化了长尾、伤害了中位数"的具体优化例子，并辩论这种交换在什么业务上值得做。
35. 闭环压测里调出来的"最优批大小"，上线后为什么常常失效？从开环/闭环差异出发，列出至少两个只有上线才会暴露的因素。
36. 火焰图采样率过低时会制造"虚假热点"：请描述这种假象的成因，并设计一个实验判断某张火焰图里的头号热点是真是假。
37. 压测达标、上线雪崩：假设协调遗漏已经排除，还有哪些环节在"骗"你的压测报告？至少说出三种。
38. 同一个 benchmark 首轮与第十轮结果相差 20%：列出至少三种解释，并设计最小实验把它们区分开。
39. 容量规划用均值而非分布会系统性低估资源：以一个均值 80 ms、P99 500 ms 的服务为例，估算按均值规划的集群在高峰时会差多少？这个误差该由哪个指标来背锅？
40. 现象诊断：重构后 perf 热点函数换了，端到端耗时却没变。候选原因：(a) 瓶颈本来就在 off-CPU；(b) 新热点只是旧瓶颈的下游影子；(c) 内存带宽已成为硬上限。请排序并说明判断证据。
41. 反直觉追问：把最热函数优化掉 30%，整体吞吐只涨 2%——除了 Amdahl 定律，还有哪些现实因素在稀释收益？
42. 取舍辩论：压测环境要不要完整复刻生产的缓存预热状态？接受冷启动数据与精确预热，哪种结论对上线更有指导性？
43. 量级估算：10k QPS、P99 目标 100 ms 的服务，每分钟有多少请求"天然"超过 100 ms？摊到一万个用户身上，单个用户一天会遇到几次？这个数字如何影响你对 SLO 投诉的处理优先级。
44. 假设破坏：如果 profiler 自身有 5% 开销、且恰好改变了锁的时序，你还能相信它给出的"锁争用"结论吗？怎样设计验证才能自洽？
45. 现象诊断：GPU 利用率显示 95%，吞吐却只有理论值的三分之一。候选原因：(a) 利用率统计把"有 kernel 在跑"当作"在算有用功"；(b) 大量小 kernel 的 launch 间隙未被计入；(c) 拷贝与计算串行化挤占了计算时间。请排序并说明你还想再要哪张图。
