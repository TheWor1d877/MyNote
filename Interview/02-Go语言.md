# Go 语言面试题库（修订版）

面向 AI Infra 方向的 Go 语言面试题库，覆盖调度器、内存与 GC、并发原语以及高并发网关工程实践，共 72 题；★ 标记为面试必会的 P0 题。

## GMP 与调度器

★1. 解释 Go 的 GMP 调度模型，G、M、P 各自承担什么职责。
2. 为什么 Go 需要 P？没有 P 的 M 和没有 M 的 G 分别处于什么状态？
★3. 解释 Go 调度器中的 work stealing 机制，以及它如何提升多核利用率。
4. 什么是 handoff？M 阻塞在系统调用时，P 和 G 会发生什么？
5. 解释 Go 的抢占式调度，协作式抢占与异步抢占的差异是什么。
★6. 什么是 goroutine 泄漏？在高并发推理网关中如何排查和避免？
★7. 解释 Go netpoll 与 epoll 的关系，以及网络 I/O 就绪后如何唤醒 G。
8. 为什么 Go 能用同步阻塞的代码风格写出高并发网络服务？
9. 解释 runtime.Gosched、runtime.LockOSThread 的使用场景与代价。
10. 什么是 GOMAXPROCS？它如何影响网关吞吐与 GPU 数据加载进程？

## 思考与取舍题

53. Go 的 GC 为什么始终不做分代？如果强行引入分代假设，Go 的哪种常见写法会第一个打破它？
54. 假设把 GC 改成"平时极快、每 10 轮 STW 一次 100ms"，推理网关最先出现什么症状？哪条监控曲线先亮？
55. 构造一个 channel 反而比 mutex 慢一个量级的场景，并指出慢在哪条路径上。
56. 逃逸分析把热路径的堆分配全部消除后，GC 压力并不会凭空消失而是发生"转移"——转到了哪里？什么现象会让你误判优化无效？
57. sync.Pool 的对象可能在两轮 GC 后被清空：什么负载下命中率会断崖式下跌？把它包成"永不过期"又会引入什么新问题？
58. goroutine 数量随流量涨落是正常水位，泄漏则是单调缓涨——如何设计告警规则把"高并发"与"慢泄漏"区分开，避免误报与漏报？
59. runtime.LockOSThread 会把 G 绑死在一个 M 上：当 cgroup 只给 2 个 CPU 配额而宿主机有 64 核时，这个绑定会怎样与配额互动出问题？
60. GOMAXPROCS 在容器里默认取宿主机核数，这个默认值在什么条件下会错？设大了与设小了分别会观察到什么症状？
61. benchmark 跑分漂亮、上线后 P99 难看——至少列出三类基准测试与真实负载之间的偏差来源。
62. 取舍辩论："context 必须穿透所有层"与"热路径上 WithTimeout 的分配开销不可接受"，双方各自的道理是什么？
63. 假设删掉 netpoll，让每条连接独占一个系统线程，1 万条 SSE 长连接的网关会以什么方式败掉？
64. 量级估算：10 万连接、每连接 3 个 goroutine 的网关，仅 goroutine 栈与运行时元数据的内存量级是多少？什么时候会突破 10GB？
65. GC 结束后 heap 的 inuse 明显下降，进程 RSS 却居高不下——列三个候选原因并按可能性排序。
