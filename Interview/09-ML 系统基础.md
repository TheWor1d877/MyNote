# ML 系统基础面试题库（修订版）

面向 AI Infra **平台岗**（Go + 云原生 + 训练/推理基础设施）的 ML 系统基础题库，覆盖训练与推理、分布式并行、显存与通信、采样与批处理的系统问题，共 60 题。

> **分层使用说明（2026-10-06 起生效，按岗位定位重新标层）**
> - **★ = P0 必会**：能脱稿讲 60–120 秒，从系统指标与工程取舍角度答，不背数学推导；
> - **P1 概念级**：节后标注「P1」的小节——能讲清"是什么、影响哪项系统指标（显存/带宽/通信/延迟）"即可，不深挖实现；
> - **P2 算法侧**：节后标注「P2」的小节——属算法工程师主场，平台岗面试**只需知道存在与边界**，本库中保留仅为知识索引，第一轮直接跳过；
> - 答题统一口径：**平台岗答 ML 题的满分姿势是"系统账"**（显存字节数、通信量、带宽利用率、对调度的影响），而不是复述算法论文。

## 训练与推理基础
