# 云原生与 AI 调度

## 必会

1. 容器和虚拟机到底差在哪？为什么说容器不是轻量级虚拟机？
2. 调度器为什么以 Pod 为单位，而不是以容器为单位？
3. StatefulSet 比 Deployment 多保证了什么？什么样的服务必须用它？
4. DaemonSet 和 Job 各适合跑什么？推理集群里哪些组件会用 DaemonSet 部署？
5. Service 和 Endpoints 是什么关系？EndpointSlice 解决了大规模下的什么问题？
6. Request 和 Limit 各管什么？CPU 的 Limit 设小了，运行时会发生什么？
7. GPU 是怎么暴露给 Kubernetes 的？Device Plugin 在里面做什么？
8. MIG、整卡分配、时间片共享，三种 GPU 分法的隔离性和代价各是什么？
9. Volume、PV、PVC、StorageClass 各管哪一段？为什么要拆成这么多层？
10. CSI 解决的是什么问题？没有它之前存储厂商怎么接入 Kubernetes？
11. HPA 和 Cluster Autoscaler 各扩的是什么？推理服务的弹性为什么比无状态 Web 服务难做？
12. 从提交一个 vLLM Pod 到它开始接流量，中间经过哪些组件、各做了什么？
