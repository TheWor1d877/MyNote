# 云原生与 AI 调度（分级版）

按重要性分三档：T1 必须能脱稿讲满 3–5 分钟；T2 能讲清 90 秒；T3 为扩展与速查。★ 仅表示原题库标记，已不完全等同 T1。

## T1 · 必须脱口而出

1. ★ 从容器本质出发，解释 namespace 与 cgroup 分别解决了隔离和资源限制中的什么问题。
2. ★ 为什么容器不是轻量级虚拟机？容器共享内核带来的性能优势和安全代价分别是什么？
3. ★ 解释 Kubernetes Pod 的设计哲学，以及为什么 Pod 是原子调度单位而不是容器。
4. ★ 解释 Deployment、StatefulSet、DaemonSet、Job、CronJob 的语义差异与适用场景。
5. ★ 解释 Service、Endpoints、EndpointSlice 的关系，以及大规模推理服务下 EndpointSlice 为什么重要。
6. ★ 什么是 eBPF？Cilium 如何利用 eBPF 做网络、可观测性和安全策略？
7. ★ 解释 Kubernetes 调度框架的扩展点：Filter、Score、Reserve、Permit、Bind 等。
8. ★ 什么是 Request 与 Limit？CPU 和内存的 Request/Limit 在调度与运行时分别如何生效？
9. ★ 什么是 Device Plugin？GPU 厂商如何通过它把 GPU 资源暴露给 Kubernetes？
10. ★ 什么是 MIG？它和整卡分配、时间片共享相比，在推理服务隔离性上有什么取舍？
11. ★ 解释 Kubernetes 中存储的核心抽象：Volume、PersistentVolume、PersistentVolumeClaim、StorageClass。
12. ★ 什么是 CSI？它如何解耦存储供应商与 Kubernetes 核心代码？
13. ★ 解释 HPA、VPA、Cluster Autoscaler、Karpenter 的差异，以及推理服务弹性扩缩容的难点。
14. ★ 从提交一个 vLLM 推理 Pod 到它开始接收流量，列出 Kubernetes 控制面、数据面、CNI、CSI、Device Plugin、kubelet、containerd 各自参与的关键步骤。

## T2 · 应当会答

15. 解释镜像分层与联合文件系统的原理，以及为什么镜像层设计会影响模型加载速度。
16. 解释 cgroup v2 在 kubelet 中的落地差异：统一层级、cpu.weight 与 memory.qos 等接口变化，以及 cgroupfs 与 systemd 两种驱动对资源管理、观测与 eBPF 生态有什么影响？
17. 什么是 Pause 容器？它在 Pod 网络与 PID namespace 共享中起什么作用？
18. ★ 解释 kube-proxy 的 iptables 模式与 IPVS 模式差异，以及高并发推理网关下如何选型。
19. 什么是 CNI？Calico、Cilium、Flannel 的基本差异是什么？
20. ★ 结合调度器扩展实战，解释 Reserve 与 Permit 扩展点的语义，以及 PodSchedulingGate 如何实现任务的门控与批量放行？在 GPU 集群中如何组合三者实现"先等待、再锁定资源、最后绑定"的调度流程？
21. 解释拓扑管理器与 CPU Manager，它们如何影响低延迟推理和 GPU 训练任务？
22. 什么是 GPU 拓扑感知调度？NVLink、PCIe、NUMA 亲和性分别如何影响多卡训练与推理的通信性能？调度器应如何利用拓扑信息打分？
23. ★ 什么是 Admission Controller？Validating 与 Mutating 的先后顺序是什么？
24. ★ 解释 Informer、InformerFactory、Lister、WorkQueue 在 controller 中的协作机制。
25. ★ 解释 etcd 在 Kubernetes 中的角色，以及 etcd 性能恶化时集群会出现哪些典型症状。
26. ★ 什么是 Leader Election？为什么高可用控制器必须处理脑裂与租约续期？
27. 什么是 Gang Scheduling？为什么分布式训练必须以 all-or-nothing 方式调度一组 Pod？部分调度会带来什么资源浪费与死锁问题？

## T3 · 扩展与速查

28. ★ 解释 runc、containerd、CRI-O、Docker 之间的关系，以及 Kubernetes 为什么最终通过 CRI 解耦运行时。
29. ★ 解释 DRA（Dynamic Resource Allocation）与 NRI（Node Resource Interface）分别解决什么问题？相比 Device Plugin，它们在资源建模、分配灵活性与节点设备可观测性上补齐了哪些能力？
30. ★ 解释 Kubernetes Operator 模式，以及为什么分布式训练框架常用 Operator 管理。
31. ★ 什么是 CRD？它和自定义控制器如何共同实现声明式 API？
32. 解释 GPU 集群中的碎片问题：小卡任务散布如何导致大卡任务无法调度？有哪些缓解碎片、提升大模型训练任务调度成功率的实践？
33. 解释 Volcano 在 AI 训练与推理调度中的角色：它提供了哪些 kube-scheduler 默认不具备的能力？
34. 什么是 OCI 镜像规范与 OCI 运行时规范？它们分别约束了哪一层？
35. 什么是 Init Container、Sidecar、Ambassador、Adapter 模式？分别适合什么 AI Infra 场景？
