# 网络内核面试题库（修订版）

覆盖内核网络收发路径、TCP 连接与拥塞控制、无损网络与 RDMA 的面试题，共 41 题，标注 ★ 的为面试必会 P0 题。

## 数据包路径与内核收发

★1. 从一次 socket send 出发，描述数据从用户态到网卡的完整路径。
★2. 从一次网卡收包出发，描述数据从硬件中断到用户态 read 返回的完整路径。
3. 解释 NAPI 与轮询机制，它如何缓解高包速率下的中断开销。
4. 什么是软中断与 ksoftirqd？它们在高吞吐网络场景中如何成为瓶颈。
★5. 解释 GRO、GSO、TSO、LRO 的作用与差异。
6. 什么是 RSS 与 RPS？它们如何把网络负载分散到多核。
7. 解释 XPS 与 IRQ affinity，如何避免网卡中断集中在一个 CPU。
8. 解释 XDP 的处理位置与 eBPF 网络加速路径，它为什么能在驱动层完成丢包、重定向与转发？

## 零拷贝与内核旁路

★9. 什么是零拷贝网络路径？sendfile、splice、MSG_ZEROCOPY 分别如何工作。
10. 解释 DPDK 的原理，以及它适合哪些网络加速场景。

## TCP 连接管理

★11. 解释 TCP 三次握手在内核中的状态机与队列：SYN queue、accept queue。
12. 什么是 SYN flood？syncookies 如何缓解。
★13. 解释 TIME_WAIT 的成因，以及大量 TIME_WAIT 对推理网关的影响。
14. 解释 tcp_tw_reuse 与 tcp_tw_recycle 的历史与风险。
15. 解释 SO_REUSEPORT 的内核分发机制，它如何在多个进程间实现连接级负载分担，并支持服务的无缝重启与滚动升级？

## TCP 流量控制与拥塞控制

★16. 解释 TCP 滑动窗口、接收窗口、发送窗口与零窗口探测。
17. 什么是 Nagle 算法与延迟确认的交互，为什么它们会叠加出延迟。
★18. 解释 TCP 拥塞控制状态机：慢启动、拥塞避免、快速重传、快速恢复。
★19. 解释 CUBIC 与 BBR 的核心思想差异，以及它们对跨机房训练数据流的影响。
★20. 什么是 ECN？它如何与 DCTCP、DCQCN 配合实现低延迟无损网络。

## RDMA 与无损网络

★21. 解释 PFC 的原理，以及它可能引发的 Head-of-Line Blocking 与死锁。
★22. 什么是 RDMA？它相比 TCP 在内核旁路、零拷贝、CPU 卸载上的优势是什么。
23. 解释 RDMA verbs 的核心对象：PD、MR、QP、CQ。
24. 什么是 RoCEv2？它为什么需要无损网络，运维难点在哪里。
25. 解释 InfiniBand 的 subnet manager 与 fabric 基本概念。
★26. 什么是 GPUDirect RDMA？它如何让网卡直接读写 GPU 显存。

## 思考与取舍题

28. 零拷贝在什么情况下是负优化？给出小包高频场景中 sendfile/MSG_ZEROCOPY 反而更慢的条件，并辩论"省下的拷贝成本"实际被转移到了哪里。
29. BBR 在广域网上常常占优，为什么在数据中心内不一定赢过 CUBIC？当瓶颈是交换机队列而非带宽时，两者的行为差异会如何放大或缓解 incast？
30. 现象诊断：跨 NUMA 部署后网络吞吐掉一半，CPU 利用率却不高。候选原因：(a) RSS 队列与处理核不在同一 NUMA 节点；(b) 收包缓冲落在远端内存拖慢拷贝；(c) 中断集中在单个核上。请排序并给出验证手段。
31. GRO 用增加一跳延迟换吞吐：在 10 Gbps 与 100 Gbps 网卡上，这个交换的临界点分别在哪里？对小包 RPC 服务你开还是不开？
32. PFC 死锁的触发条件是什么？辩论一下：一个从未出过死锁的无损网络，究竟是"配置正确"还是"条件还没凑齐"？
33. syncookies 开启后，TCP 握手的哪些信息会丢失或被降级？对一个依赖这些选项的推理网关，攻击结束后应不应该立刻关掉它？
34. 长短连接混合的推理网关出现数万 TIME_WAIT：把下面威胁按真实程度排序并说明理由——(a) 临时端口耗尽导致无法建连；(b) 内核连接哈希查找变慢；(c) 内存占用拖垮主机。
35. 现象诊断：网关每天固定时段 P99 抖动，抓包可见集中重传。候选原因：(a) 定时批量任务引发 incast；(b) 监控采集抢占软中断 CPU；(c) 上游交换机缓存溢出丢包。请排序并说明你先查哪个计数器。
36. 反直觉追问：把网卡 ring buffer 调到最大后丢包反而变多——给出至少两种机制上的解释。
37. 取舍辩论：内核旁路（DPDK/XDP）占用的 CPU 核若留给推理服务还能多跑请求：在什么利用率水平下旁路才划算？
38. 量级估算：100 Gbps 链路上 1500 字节包的每秒包数是多少？若每包处理预算要压进 1 微秒，需要几颗核专职收包？据此评估"内核协议栈够不够用"这句话。
39. 假设破坏："带宽充足时，拥塞控制算法对延迟没有影响"——用一次 incast 场景击碎这句话，并指出此时真正稀缺的资源是什么。
40. 现象诊断：RDMA 集合通信偶发秒级超时，交换机上有 PFC pause 帧但零丢包。候选原因：(a) PFC 水线配置不当引发下游风暴；(b) Head-of-Line Blocking 在某条链路累积；(c) 对端 GPU 侧停顿反向传导。请排序并说明排序依据。
41. SO_REUSEPORT 的连接分发看似均匀，为什么实际负载常集中于少数 worker？在不改内核的前提下，你在调度层面有什么补救思路？

## 综合设计题

27. 如果让你为分布式训练设计一个跨节点数据与梯度传输的网络层，你会如何组合 TCP、RDMA、拥塞控制、拓扑感知与故障降级？
