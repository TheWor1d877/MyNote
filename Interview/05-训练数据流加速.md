# 训练数据流加速（分级版）

按重要性分三档：T1 必须能脱稿讲满 3–5 分钟；T2 能讲清 90 秒；T3 为扩展与速查。★ 仅表示原题库标记，已不完全等同 T1。

## T1 · 必须脱口而出

1. ★ 从一次训练 step 出发，描述数据从存储到 GPU 显存的完整路径，并标出所有可能阻塞的环节。
2. ★ 什么是 GPU 数据加载瓶颈？如何判断瓶颈在 CPU、内存、PCIe、网络、存储还是框架层？
3. ★ 解释 DataLoader 的工作原理，以及 num_workers、prefetch_factor、pin_memory 分别影响什么。
4. ★ 什么是异步预取？如何在 Go 或 Python 中实现可控的异步数据预取？
5. ★ 解释双缓冲与多缓冲机制，以及它们在数据加载 pipeline 中的应用。
6. ★ 什么是 backpressure？数据加载 pipeline 中如何避免生产者压垮消费者？
7. ★ 什么是数据预热？如何在训练开始前把热数据预取到 page cache 或本地 NVMe？
8. ★ 什么是缓存命中率？如何针对训练数据访问模式设计缓存策略？
9. ★ 什么是数据局部性？训练数据分片如何与节点、机架、GPU 拓扑对齐？
10. ★ 什么是 cache-aware 调度？Kubernetes scheduler plugin 如何感知节点上的缓存位置并据此打分？
11. ★ 解释 checkpoint 写入对训练数据流的冲击，以及如何做异步 checkpoint。
12. ★ 解释 S3 的 range 读，以及它如何支持分片并行读取训练数据。
13. ★ 解释 straggler 问题，以及数据分片不均衡如何造成训练慢节点。
14. 如果让你设计一个面向大模型训练的“数据流加速层”，你会从存储、缓存、预取、格式、网络、GPU 通路哪些维度给出架构原则？
15. ★ 在 PyTorch DataLoader 中，num_workers > 0 时数据是如何跨进程传递的？
16. ★ 什么是 pin_memory？在 DataLoader 中它如何与 CUDA 拷贝配合？

## T2 · 应当会答

17. 什么是 H2D 拷贝？CUDA Stream（默认流与多流）与 CUDA Event 如何在数据加载与计算重叠中协作，并做精确计时？
18. ★ 解释 WebDataset 格式的设计动机，以及它为什么适合大规模训练数据流。
19. ★ 什么是 sharded dataset？分片粒度如何影响顺序读、随机读和负载均衡？
20. ★ 什么是 Arrow？它为什么适合零拷贝数据交换和跨语言数据管道？
21. ★ 解释本地 NVMe 缓存在训练数据流中的作用，以及如何做缓存淘汰。
22. ★ 数据集版本化如何与缓存失效保持一致？数据变更后如何避免训练读到新旧混杂的缓存？
23. 训练场景“单写多读”的缓存一致性假设何时失效？失效后需要什么机制补救？
24. ★ 解释数据亲和性调度，以及它如何减少跨网络数据读取。
25. 解释 cgroup blkio 与 io.max 对训练数据读取的限速作用。
26. ★ 训练数据管道的混沌测试如何设计？应注入哪些故障、验证哪些指标？
27. ★ 什么是 checkpoint 分片？它如何提升大模型检查点写入和恢复速度？
28. ★ 什么是模型权重预取？如何在推理服务启动时隐藏模型加载延迟？
29. ★ 什么是对象存储的 multipart upload？它如何加速大文件写入和检查点保存？
30. ★ 什么是 P99 延迟？为什么数据加载的尾延迟会拖慢整体训练吞吐？
31. 把海量小文件合并成大分片换来了顺序吞吐，但"随机访问单条样本"与"流式断点续读"的代价会发生什么变化？描述一个明显不适合合并的访问模式。
32. ★ 什么是数据管道可观测性？应该采集哪些延迟、吞吐、队列深度指标？
33. ★ 解释 CPython 的 GIL 是什么，它保护了什么，又不保护什么。
34. ★ 解释 Python 多线程、多进程、asyncio 三种并发模型的适用场景与代价。

## T3 · 扩展与速查

35. 对象存储 range 读在"64 并发 × 8MB"时打满带宽，改成"16 并发 × 32MB"后掉了一半——总在途字节相同，结果为什么不同？请从拥塞窗口、单流上限与存储端分片布局三个角度说理。
36. 预取深度调到 32 后，固定 shuffle 种子的基准吞吐提升 40%，换一种数据顺序就跌回原样甚至更差。为什么会出现"对 page cache 的过拟合"？如何设计一个不被数据顺序愚弄的评测方法？
37. 什么是数据加载的端到端 profiling？如何用 Nsight、PyTorch Profiler、eBPF 联合定位瓶颈？
38. 解释模型加载路径：从对象存储到 GPU 显存，中间经过哪些缓存与拷贝。
39. ★ 解释 Python 对象序列化 pickle 的开销，以及它如何影响 DataLoader 吞吐。
40. ★ 解释 PyTorch Sampler 与 DistributedSampler 的工作原理，以及 epoch 边界如何处理。
41. ★ 如果让你优化一个 PyTorch 训练数据加载 pipeline，你会从 GIL、多进程、共享内存、序列化、pin memory、CUDA Stream 哪些角度入手？
42. 什么是共享内存？Python 中如何用 shared_memory 或 mmap 降低数据拷贝？
