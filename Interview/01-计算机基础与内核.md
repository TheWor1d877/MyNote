# 计算机基础与内核（AI Infra 分级版）

按重要性分三档：T1 必须能脱稿讲满 3–5 分钟；T2 能讲清 90 秒；T3 为扩展与速查。★ 仅表示原题库标记，已不完全等同 T1。

## T1 · 必须脱口而出

1. ★ 什么是存储层次结构？寄存器、L1/L2/L3 Cache、主存、NVMe SSD、网络存储的延迟量级大致是多少？
2. ★ 解释 Cache Line 的概念，以及为什么 false sharing 会严重伤害多线程程序性能。
3. ★ 什么是零拷贝？列举 Linux 中常见的零拷贝技术，并说明各自适用场景。
4. 解释用户态与内核态切换的开销来源，以及系统调用为什么可能成为推理网关的瓶颈。
5. ★ 什么是 epoll？水平触发与边缘触发的区别是什么？在 Go netpoll 中如何体现？
6. ★ 什么是 page cache？它如何影响训练数据读取、模型加载和日志写入性能？
7. ★ 解释 buffered I/O 与 direct I/O 的区别，以及 O_DIRECT 在数据库和分布式存储中的取舍。
8. ★ 什么是 io_uring？它相比 epoll + 传统 AIO 有哪些优势？适合哪些 AI Infra 场景？
9. ★ 解释 RDMA 的基本原理，以及它在分布式训练 AllReduce、参数同步和存储访问中的价值。
10. ★ 解释 GPU 与 CPU 之间的数据通路：PCIe、NVLink、NVSwitch 的带宽和拓扑差异。
11. ★ 什么是 GPUDirect Storage？它试图解决什么问题？对训练数据流加速意味着什么？
12. 解释 cgroup 与 namespace 的区别，以及它们如何共同构成容器隔离的基础。
13. ★ 从一次推理请求进入网关开始，到 GPU 返回 token，列出沿途可能涉及的操作系统、网络、存储、GPU 数据通路关键环节。
14. ★ 从一次 socket send 出发，描述数据从用户态到网卡的完整路径。
15. ★ 从一次网卡收包出发，描述数据从硬件中断到用户态 read 返回的完整路径。
16. ★ 什么是 RDMA？它相比 TCP 在内核旁路、零拷贝、CPU 卸载上的优势是什么。

## T2 · 应当会答

17. 从 CPU 执行一条指令的完整流程出发，说明取指、译码、执行、访存、写回五个阶段中，哪些阶段可能成为 AI 训练任务的数据瓶颈。
18. 什么是 NUMA？在 Kubernetes 节点上跑多 GPU 训练任务时，NUMA 绑定为什么重要？
19. ★ 什么是虚拟内存？页表、TLB、缺页异常分别解决什么问题？
20. 解释大页内存的原理，以及它在 GPU 训练数据加载和 KV Cache 管理中的潜在价值。
21. ★ 解释 buddy system 与 slab 分配器的原理：buddy 如何通过伙伴块的分裂与合并减少外部碎片？slab 如何在 buddy 之上减少内部碎片并缓存高频分配的对象？
22. 解释 CPU 缓存一致性协议 MESI，以及多核环境下共享数据结构的性能陷阱。
23. 把 L3 缓存扩大 4 倍但访问延迟翻倍，对训练吞吐未必是好事——什么样的负载特征会让这笔交易亏损？
24. 大页能减少 TLB miss，但请各构造一个它让缺页处理变慢、让内存碎片恶化的反例。
25. 训练节点内存带宽已经打满，CPU 利用率却只有 30%——列三个候选原因并按可能性排序。
26. 节点 free 显示还有几百 GB available，新进程却触发 OOM——列三个候选原因并按可能性排序。
27. 什么是 DMA？为什么高性能网络和存储设备几乎都依赖 DMA？
28. 解释中断、软中断、下半部机制，以及它们对高吞吐 I/O 场景的影响。
29. 解释进程、线程、协程的区别，以及 Go runtime 调度器如何映射到操作系统线程。
30. 解释 Reactor 与 Proactor 模式，并说明它们在高并发推理网关中的适用性。
31. epoll 边缘触发相比水平触发省下的系统调用开销最终去了哪里？什么条件下这点节省会被读写循环的复杂度反噬？
32. 零拷贝在 TLS 网关里往往名存实亡——哪些中间层会把"零拷贝"悄悄变回两次拷贝？
33. 解释 ext4、XFS、Btrfs 的基本设计差异，以及它们对大规模小文件训练数据集的影响。
34. 什么是 inode？inode 耗尽会导致什么问题？如何排查和缓解？
35. 解释 SSD 的读写放大、垃圾回收、TRIM，以及它们对高吞吐数据管道的影响。
36. ★ 解释 TCP 三次握手与四次挥手，以及 TIME_WAIT 过多对推理网关的影响。
37. 什么是 TCP 粘包与拆包？在自定义 RPC 协议中如何设计消息边界？
38. ★ 解释 TCP 三次握手在内核中的状态机与队列：SYN queue、accept queue。
39. ★ 解释 TIME_WAIT 的成因，以及大量 TIME_WAIT 对推理网关的影响。
40. ★ 解释 TCP 拥塞控制状态机：慢启动、拥塞避免、快速重传、快速恢复。
41. ★ 解释 CUBIC 与 BBR 的核心思想差异，以及它们对跨机房训练数据流的影响。
42. ★ 什么是 ECN？它如何与 DCTCP、DCQCN 配合实现低延迟无损网络。
43. ★ 解释 PFC 的原理，以及它可能引发的 Head-of-Line Blocking 与死锁。
44. ★ 什么是 GPUDirect RDMA？它如何让网卡直接读写 GPU 显存。

## T3 · 扩展与速查

45. 解释 FUSE 的原理，以及它为什么可能成为训练数据流加速中的性能瓶颈。
46. 解释 cgroup v1 与 v2 的主要差异：统一层级、no-internal-process 约束、控制器委托与 PSI 压力反馈，对容器运行时和 Kubernetes 资源管理有什么影响？
47. 解释 Nagle 算法与 TCP_NODELAY，以及它们对低延迟推理请求的影响。
48. 解释 HTTP/1.1、HTTP/2、HTTP/3 的关键差异，以及 gRPC 为什么常基于 HTTP/2。
49. 什么是 TLS 握手？会话复用、0-RTT、mTLS 在服务网格和推理网关中的作用是什么？
50. 把网卡中断绑定到与 GPU 同 NUMA 的核上，为什么有时反而让那个核成为瓶颈？该怎么判断该绑还是该分散？
51. 取舍辩论：跨机训练流量走 RDMA 还是 TCP？从运维代价、故障域与带宽利用率三个角度，TCP 阵营最硬的牌是什么？
52. 解释内存映射 I/O 与端口映射 I/O 的区别，以及它们在设备驱动中的典型应用。
53. 解释 Linux 中一切皆文件的设计哲学，以及它对设备、管道、socket、cgroup 抽象的影响。
54. 解释硬链接与软链接的区别，以及它们在容器镜像层中的表现形式。
55. 什么是 VFS？它如何统一不同文件系统的接口？
56. 什么是死锁、活锁、饥饿？在分布式训练任务调度中如何避免？
57. ★ 什么是零拷贝网络路径？sendfile、splice、MSG_ZEROCOPY 分别如何工作。
58. BBR 在广域网上常常占优，为什么在数据中心内不一定赢过 CUBIC？当瓶颈是交换机队列而非带宽时，两者的行为差异会如何放大或缓解 incast？
59. PFC 死锁的触发条件是什么？辩论一下：一个从未出过死锁的无损网络，究竟是"配置正确"还是"条件还没凑齐"？
60. 现象诊断：RDMA 集合通信偶发秒级超时，交换机上有 PFC pause 帧但零丢包。候选原因：(a) PFC 水线配置不当引发下游风暴；(b) Head-of-Line Blocking 在某条链路累积；(c) 对端 GPU 侧停顿反向传导。请排序并说明排序依据。
61. 什么是软中断与 ksoftirqd？它们在高吞吐网络场景中如何成为瓶颈。
62. 什么是 RSS 与 RPS？它们如何把网络负载分散到多核。
