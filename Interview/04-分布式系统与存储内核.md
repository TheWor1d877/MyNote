# 分布式系统与存储内核（分级版）

## T1 · 必须脱口而出

1. ★ 解释 CAP 定理的准确含义，以及为什么它常被误解为「三选二」。
2. ★ 解释线性一致性、顺序一致性、因果一致性、最终一致性的强弱关系与典型系统。
3. ★ 什么是线性一致读？为什么它在分布式存储中实现成本很高？
4. ★ 解释租约机制，以及它在分布式锁、Leader 选举和缓存一致性中的作用。
5. ★ 什么是 Quorum？W + R > N 为什么能保证强一致读？
6. ★ 什么是 Raft？描述 Leader 选举、日志复制、安全性约束的核心流程。
7. ★ Raft 中 term 的作用是什么？为什么旧 term 的日志不能随意提交？
8. ★ 什么是租约读？它如何避免每次读都走 Raft 日志？
9. ★ 解释 Raft 的 ReadIndex 与 Lease Read 两种线性一致读实现的差异，以及它们各自的适用场景。
10. ★ 什么是分布式系统中的脑裂？如何通过 Quorum、Fencing、STONITH 等手段缓解？
11. ★ 什么是一致性哈希？它如何解决节点扩缩容时的数据迁移问题？
12. ★ 什么是纠删码？它相比多副本在存储成本与恢复开销上的取舍是什么？
13. ★ 解释对象存储、块存储、文件存储的差异，以及它们分别适合 AI 训练中的哪类数据。
14. ★ 什么是 JuiceFS、Alluxio、CubeFS 这类分布式文件系统？它们的核心抽象和缓存策略是什么？
15. ★ 从一次分布式训练任务读取样本开始，到样本进入 GPU 显存，列出可能涉及的元数据服务、缓存层、存储后端、网络传输与本地 I/O 关键环节。
16. ★ 从一次 read 系统调用出发，描述数据从磁盘到用户态缓冲区的完整路径。
17. ★ B+ 树与 LSM-tree 相比，各自的读放大与写放大来自哪里？如何根据读写比例与空间预算做取舍？
18. ★ 如果让你为训练数据读取设计一个单机存储加速层，你会如何组合 page cache、direct I/O、io_uring、预读、本地 NVMe 缓存与 FUSE 旁路？

## T2 · 应当会答

19. 什么是逻辑时钟？Lamport 时钟与向量时钟分别解决什么问题？
20. 解释 MVCC 的原理，以及它如何支撑快照读与无锁读。
21. 什么是幂等性？在分布式存储和推理网关中如何设计幂等接口？
22. 解释 Raft 的成员变更问题，以及单步变更与联合共识的差异。
23. Raft 已经有租约读这种开销低的线性一致读，为什么不干脆用它满足一切读，把 ReadIndex 留作备用？
24. ★ 解释 Fencing Token 的作用，以及它在分布式锁和存储访问中的意义。
25. 解释 Merkle Tree 在分布式存储反熵与数据校验中的应用。
26. 解释副本放置策略中的机架感知、可用区感知与故障域隔离。
27. 解释数据分片与 Shuffle，以及它们对分布式训练吞吐和存储 I/O 的影响。
28. 什么是数据预取？在训练数据加载中，预取如何与 GPU 计算重叠？
29. 量级估算：跨机房部署（单向 RTT 30ms）的 Raft 组，一次提交至少要多久？commit 等待与 fsync 的耗时为什么相加、不能并行？
30. ★ 解释缓存一致性协议在分布式缓存中的体现，以及缓存穿透、击穿、雪崩的区别。
31. ★ 从一次 write 系统调用出发，描述数据从用户态到持久化介质的完整路径。
32. ★ 什么是 O_SYNC、O_DSYNC、fsync、fdatasync 的差异。
33. 解释 blk-mq 多队列块层，以及它如何适配 NVMe 高并发。
34. ★ 解释 bitcask 模型：全内存哈希索引、追加写日志文件与定期合并如何协作？它适合什么样的负载？
35. 对比 crash consistency 的三条实现路径：journal（日志）、shadow paging（影子页）与 COW（写时复制），各自的原理、运行时开销与崩溃恢复方式是什么？
36. ★ 什么是写放大？它在 SSD、RAID、CoW 文件系统中分别如何产生。
37. ★ 解释 SSD 的 FTL、垃圾回收、TRIM、磨损均衡。
38. 模型权重在容器里通常被假设只读：什么操作会触发 overlayfs copy-up 打破这个假设？若平台每天启动数百个容器加载同一个 20 GB 权重文件，copy-up 的代价发生在哪里？
39. ★ 解释 page cache 的读缓存与写缓存分别如何工作。
40. ★ 解释 direct I/O 的语义，以及它和 page cache 的交互。
41. ★ 什么是 io_uring？它的 submission queue 与 completion queue 如何工作。
42. ★ 解释 overlayfs 的读路径与写路径，以及它对容器启动和模型加载的影响。
43. 什么是 overlayfs 的 copy-up？它如何影响首次写入性能。
