# 推理引擎优化（修订版）

面向大模型推理方向的面试题库，覆盖 vLLM 架构与源码、KV Cache 管理、批处理调度、并行通信、投机解码、PD 分离与高并发网关，共 133 题；★ 前缀为该方向面试必会题。

> **分层使用说明（2026-10-06 起生效）**
> - **★ = P0**：TTFT/TPOT、continuous batching、KV Cache 管理（PagedAttention、prefix caching、offload）、网关路由与限流、弹性扩缩容、PD 分离架构权衡——与 P2 项目直接咬合；
> - **P1 概念级**：投机解码、Tensor Parallel、pipeline parallel、LoRA 热加载、容量规划与成本模型——知道做什么、对调度/成本有什么影响即可；
> - **P2 跳过**：量化推理（33–34）、FlashAttention 原理、kernel fusion、CUDA Graph、动态 shape、vLLM 多实例 GPU 部署细节（35–45）——推理引擎 kernel/驱动层工程师主场，平台岗只需知道"FlashAttention 降低访存、CUDA Graph 降低 launch 开销、量化降显存但可能影响精度"；
