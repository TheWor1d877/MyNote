# 数字账与容量估算

## 必会

1. 每秒 10 万请求、每请求 20 次系统调用的网关，系统调用大概要吃掉几个核？加核能解决这个问题吗？
2. 把 100 GB 的 checkpoint 从 NVMe 加载进 8 张卡，最短要多久？瓶颈卡在哪一段？
3. 一个 70B 模型、32k 上下文的请求，KV Cache 要占多少显存？一张 80 GB 的卡能同时服务几路这样的请求？
4. 128K 上下文、32 路并发的 70B 模型，KV Cache 要多少显存？一张 80 GB 的卡能同时跑几路？
5. 一次任务 40 步、上下文从 8K 涨到 100K，KV 占用曲线长什么样？容量按峰值备还是按均值加缓冲？
6. SLO 要求每个请求平均输出 200 token、每 token 50ms，单卡能扛 64 路并发，目标 1000 QPS，大概要多少卡？

## 加分

7. 后端处理要 30 秒，客户端超时 10 秒、失败重试两次，一次一分钟的卡顿最坏会灌进去多少请求？客户端早就放弃了，后端还在为谁烧 GPU？
8. 预取层把训练的数据等待从 17% 降到 5%，一个 128 卡跑 7 天的任务省出多少卡时？这笔账里最脆的假设是哪一步？
9. Agent 一次任务平均 40 次模型调用、每次带 8K 上下文，单任务 token 量是一问一答的多少倍？这个倍数怎么进容量规划？
10. 跨机架 RTT 0.2 ms、跨 AZ 5 ms，Agent 一次任务 40 步，这两个延迟各放大成多少端到端时间？哪些调用该做同 AZ 亲和？

## 参考：量级速查

延迟梯度：

| 层级 | 量级 |
|---|---|
| L1 缓存 | ~1 ns |
| L3 缓存 | ~10–30 ns |
| 主存随机访问 | ~80–120 ns |
| NVMe SSD 读 | ~10–100 μs |
| 同机架 RTT | ~0.1–0.5 ms |
| 跨可用区 RTT | ~1–10 ms |
| 对象存储首字节 | ~10–100 ms |
| 一次系统调用 | ~1–3 μs |

带宽与容量：

| 链路 | 量级 |
|---|---|
| NVMe SSD 顺序读（Gen4 x4） | 3–7 GB/s |
| PCIe 4.0 x16 | 32 GB/s（有效 ~25） |
| PCIe 5.0 x16 | 64 GB/s（有效 ~50） |
| 100 GbE | 12.5 GB/s |
| 400 Gb RDMA | 50 GB/s |
| NVLink（代际差大） | 300–900 GB/s |
| HBM（A100 → H100/H200） | 2 → 3.5–4.8 TB/s |
| 单卡显存 | 40–141 GB |

单价口径（波动大，报数前核实）：GPU 卡·小时、对象存储每 GB·月加请求费、出口带宽每 GB、每百万 token 的生产成本。
