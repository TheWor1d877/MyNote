# 训练数据流加速

## 必会

1. 从一次训练 step 出发，数据从对象存储到 GPU 显存经过哪些环节？标出每一段可能阻塞的位置。
2. GPU 每步都在等数据，怎么判断瓶颈在 CPU 解码、内存、PCIe、网络、存储还是框架层？各用什么证据排除？
3. DataLoader 开多 worker 之后数据怎么跨进程返回？num_workers 和 prefetch_factor 各控制哪一段？
4. DataLoader 打开 pin_memory 后改变了什么？它和后面的 H2D 拷贝怎么接上？
5. 异步预取要控制哪几个量？预取深度和内存预算各防止什么问题？生产者超过消费者速度时，背压怎么设计？
6. 双缓冲和多缓冲在数据管道里怎么配合？缓冲份数由哪些因素决定？
7. 训练开始前怎么做数据预热？把热数据提前放进 page cache 或本地 NVMe，各适合什么场景？
8. 训练数据按 epoch 扫描，可能带 shuffle，也可能被多个任务共读。缓存策略怎么针对这些访问模式设计？
9. 数据分片怎么和节点、机架对齐？cache-aware 调度怎么知道缓存位置，位置过期后怎么办？
10. 对象存储的 range 读怎么支持分片并行？并发数和单次读取大小怎么配置？
11. 数据分片不均衡为什么会产生慢节点？一个 rank 读得慢，为什么其他 rank 也要等待？
12. checkpoint 写盘会和数据读取争哪些资源？异步 checkpoint 把哪一段挪出了关键路径？
13. 海量小文件为什么要合并成大分片？分片粒度太大和太小分别伤害顺序读、随机读还是负载均衡？
14. 数据缓存命中率怎么测？哪些统计口径会让命中率虚高？
15. 数据管道要采哪些指标？延迟、吞吐和队列深度分别看哪个位置，才能定位等待发生在哪一段？
16. GIL 保护什么、不保护什么？DataLoader 为什么常用多进程执行解码？
17. 跨进程传递 tensor 的序列化和拷贝开销在哪？共享内存怎么减少开销，代价是什么？
18. range 读改成 64 并发乘 8MB 后能打满带宽，16 并发乘 32MB 反而掉一半。总在途字节相同，为什么结果不同？

## 加分

1. 数据集发布新版本后，缓存怎么失效？版本号不进入缓存键会发生什么？
2. 单写多读的缓存一致性假设在训练场景什么时候失效？失效后怎么补救？
3. 多租户集群里，怎么防止一个租户的预取挤占另一个租户的缓存和带宽？共享与隔离的边界怎么划？
4. 预取深度调大后，固定 shuffle 种子的基准变好，换数据顺序又变差。评测怎么避免被数据顺序误导？
5. 图像解码和视频抽帧各产生多少读放大？解码放到 GPU 后省掉了哪一段拷贝？
6. 变长样本拼成定长序列消除了哪项浪费？拼接后跨样本的注意力 mask 怎么构造？位置编码按文档重置和整条连续各付出什么？
