# C++ 与系统编程（项目向）

C++ 是第二语言，项目里有 C++/C ABI 实现。按"能读改、能写边界"的深度准备：不考模板元编程，考资源生命周期、跨语言边界与热路径性能。

## T1 · 必须脱口而出

1. 以 RAII 为主线，解释 C++ 如何同时保证异常安全与资源释放；构造/析构顺序、拷贝与移动对资源所有权分别有什么影响？
2. unique_ptr、shared_ptr、weak_ptr 的所有权语义与运行时开销分别是什么？在 C ABI 边界上传递资源时，如何避免所有权不清导致的双重释放？
3. 解释 std::atomic 的 relaxed/acquire/release/seq_cst：在无锁队列或共享环形缓冲区里，生产者与消费者各自该用哪一种，为什么？
4. 解释结构体对齐与 padding，以及 false sharing 的成因；如何用字段重排、alignas 与批量布局降低热路径的缓存行占用？
5. 如果让你用 C++ 封装一层 RDMA verbs（或类似的 C 库）给上层 Go/Python 调用，你会如何设计资源生命周期、错误处理与 C ABI 边界？

## T2 · 应当会答

6. std::move 实际移动了什么？移动构造与移动赋值在什么情况下会退化成拷贝，如何避免？
7. 解释预处理、编译、汇编、链接的全过程；为什么 C++ ABI 兼容比 C 难？-fvisibility=hidden 与 inline namespace 各解决什么问题？
8. extern "C" 解决了什么？异常能不能跨过 C 边界？跨语言错误处理该用错误码、返回值还是回调？
9. malloc/free、jemalloc/tcmalloc 与对象池在高吞吐数据管道中的取舍是什么？如何判断瓶颈在分配器而不是业务逻辑？
10. Go 通过 cgo 调用 C++ 库时，调用开销、阻塞调用对 P 的影响、跨边界内存所有权分别该怎么处理？

## T3 · 扩展与速查

11. 虚函数表如何工作？虚调用比普通调用多哪些开销？CRTP 与 std::variant 分别在什么场景替代运行时多态？
12. 哪些常见写法属于未定义行为？编译器可能如何利用 UB 做出反直觉的优化？
13. volatile、atomic 与内存屏障的区别是什么？各自能解决与不能解决什么问题？
14. 编译器自动向量化需要满足哪些条件？什么情况下手写 SIMD 才划算？
15. 静态链接与动态链接对容器镜像大小、启动时间和依赖管理分别有什么影响？
16. 无锁队列的 ABA 问题如何产生？tagged pointer、hazard pointer、epoch reclamation 各自适合什么场景？
17. AoS 与 SoA 两种布局分别适合什么访问模式？在列式处理与 GPU 传输场景中如何选？
