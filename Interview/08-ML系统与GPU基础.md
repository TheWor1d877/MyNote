# 训练并行与容错

## 必会

1. 数据并行、张量并行、流水线并行各切哪一维？每步的通信是什么形态，量随什么涨，各落在哪种互联上？
2. AllReduce、AllGather、ReduceScatter 三个集合通信各是什么语义？它们之间有什么关系式？
3. ring AllReduce 的每卡通信量为什么几乎和卡数无关？它省的是什么、赔的是什么？小消息高频同步时先撞上哪一头？
4. ZeRO 三个阶段各切什么？每阶段的通信形态和上一阶段比改在哪？为什么通常先做第一阶段？
5. DDP 和 FSDP 各把什么切了、每步跑哪些集合通信、通信量差多少？什么规模下值得付 FSDP 那笔多出来的通信？
6. bf16 混合精度加 Adam，每个参数 16 字节的静态显存账是怎么构成的？哪一项占大头？
7. 流水线并行的气泡占比怎么算？加 stage、加 microbatch、换 interleaved 调度，三件事各改哪个变量？
8. 一个 step 里数据加载、前反向、通信怎么重叠？重叠失败在指标上长什么样，两种形态怎么区分？
9. checkpoint 的保存和恢复各怎么算账？异步保存解决哪一段，代价落在哪？
10. checkpoint 间隔怎么定？保存成本和故障间隔怎么进同一个式子？间隔太短会挤占什么？
11. 训练任务挂了怎么自动拉回来？默认配置下为什么节点掉队后只是卡到超时、不会自动重启？这个误诊怎么破？
12. goodput 和 MFU 各是什么口径？大规模训练的故障率怎么进容量账？万卡集群的实测中断频率是什么量级？

## 加分

13. TP 之外还有序列并行、上下文并行、专家并行，各解决什么问题？通信点分别落在哪？
14. MoE 把参数量和每 token 计算量解耦之后，显存账和算力账为什么要分开算？门控路由给负载均衡提出哪三条要求？
15. 通信和计算的重叠有哪几类实现？各在什么条件下失效？通信 kernel 本身占 SM 这件事为什么常被忽略？
16. 千卡训练挂一次，恢复时间拆成哪四段？哪一段在千卡规模下最大？为什么 checkpoint 必须每 rank 写自己的分片而不是汇总写一份？
17. bf16、fp16、FP8 三档精度各对系统提什么要求？降精度省的是显存还是带宽，谁受益取决于什么？
18. 训练侧要确定性，到底在要求什么？「和旧实现逐位一致」与「多次运行可复现、误差达标」是同一件事吗？不确定性从哪来，开关的代价落在哪？
19. 拿到一个训练脚本，怎么快速判断它用的是哪种并行？看哪几个读点，profiler 里数什么？
20. MLA 把 KV 缓存成什么？和 GQA 比省的是式子里的哪一项？缓存层、路由层、传输层各要跟着改哪个前提？
