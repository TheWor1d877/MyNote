# Go 语言与高并发网关（分级版）

## T1 · 必须脱口而出

1. ★ 解释 Go 的 GMP 调度模型，G、M、P 各自承担什么职责。
2. ★ 解释 Go 调度器中的 work stealing 机制，以及它如何提升多核利用率。
3. ★ 解释 Go netpoll 与 epoll 的关系，以及网络 I/O 就绪后如何唤醒 G。
4. ★ 解释逃逸分析，以及哪些常见写法会让变量逃逸到堆上。
5. ★ 解释 Go GC 的三色标记法，白色、灰色、黑色分别代表什么。
6. ★ 解释 Go 的 channel 底层结构，发送、接收、关闭分别做了什么。
7. ★ 什么是限流器？如何用 token bucket 在 Go 网关中实现平滑限流。
8. ★ 解释 Go 中的背压，如何用有缓冲 channel 和信号量控制并发。
9. ★ 什么是优雅关闭？如何让 HTTP server 在滚动更新时不丢请求。
10. ★ 如果让你用 Go 写一个 vLLM 前面的高并发推理网关，你会如何设计 goroutine 模型、连接管理、限流、超时、背压与优雅关闭？

## T2 · 应当会答

11. 什么是 handoff？M 阻塞在系统调用时，P 和 G 会发生什么？
12. 什么是 GOMAXPROCS？它如何影响网关吞吐与 GPU 数据加载进程？
13. 解释 Go 的内存分配器：mcache、mcentral、mheap 的层级结构。
14. 解释 GC assisted，为什么分配快的 goroutine 会被拉去帮忙做 GC。
15. 解释 sync.Pool 的原理，以及它在网关请求对象复用中的适用条件与常见错误。
16. ★ 什么是 context？context 的取消传播在推理网关中如何工作？
17. ★ 解释 Go 的内存模型，happens-before 关系如何保证并发可见性。
18. ★ 解释 singleflight 的原理，以及它在模型权重加载、缓存回源中的应用。
19. ★ 在 SSE 长连接推理网关中，goroutine 泄漏的典型场景有哪些？如何用 pprof 的 goroutine profile 定位泄漏点与阻塞调用栈？
20. ★ 解释 Go 的 pprof：CPU、heap、block、mutex、goroutine profile 分别怎么看。
21. 什么是 trace？如何用 go tool trace 分析调度延迟与 GC 抖动。
22. 在 K8s 控制器中，Informer 与 WorkQueue 如何利用 Go 并发原语协作？
23. GOMAXPROCS 在容器里默认取宿主机核数，这个默认值在什么条件下会错？设大了与设小了分别会观察到什么症状？

## T3 · 扩展与速查

24. 为什么 Go 需要 P？没有 P 的 M 和没有 M 的 G 分别处于什么状态？
25. ★ 什么是写屏障？混合写屏障解决了什么问题？
26. ★ 解释 Go 泛型的实现方式（GC shape stenciling）：为什么泛型没有对所有类型做单态化？接口装箱又会对热路径性能造成哪些影响？
27. 解释 atomic 包提供的内存序语义，以及它在无锁结构中的应用。
28. 解释 WaitGroup 的正确用法，以及常见的 Add 与 Wait 竞态错误。
29. ★ 什么是 goroutine 泄漏？在高并发推理网关中如何排查和避免？
30. 什么是内存归还？Go 什么时候把内存还给操作系统？
31. 什么是 CAS？如何用 CAS 实现无锁计数器或队列？
32. 什么是内存逃逸与 false sharing 在 Go 中的表现，如何用 padding 缓解？
33. 解释 Go 的 unsafe.Pointer 与 uintptr 的区别，以及使用 unsafe 的风险。
