# 计算机基础面试题库（修订版）

面向 AI Infra 方向的计算机基础面试题库，覆盖体系结构、操作系统、存储、网络与 GPU 数据通路，共 73 题；★ 标记为面试必会的 P0 题。

## CPU、缓存与 NUMA

1. 从 CPU 执行一条指令的完整流程出发，说明取指、译码、执行、访存、写回五个阶段中，哪些阶段可能成为 AI 训练任务的数据瓶颈。
2. ★ 什么是存储层次结构？寄存器、L1/L2/L3 Cache、主存、NVMe SSD、网络存储的延迟量级大致是多少？
3. ★ 解释 Cache Line 的概念，以及为什么 false sharing 会严重伤害多线程程序性能。
4. 什么是 NUMA？在 Kubernetes 节点上跑多 GPU 训练任务时，NUMA 绑定为什么重要？

## 中断、DMA 与 I/O 通路

5. 解释内存映射 I/O 与端口映射 I/O 的区别，以及它们在设备驱动中的典型应用。
6. 什么是 DMA？为什么高性能网络和存储设备几乎都依赖 DMA？
7. 解释中断、软中断、下半部机制，以及它们对高吞吐 I/O 场景的影响。
8. ★ 什么是零拷贝？列举 Linux 中常见的零拷贝技术，并说明各自适用场景。
9. 解释用户态与内核态切换的开销来源，以及系统调用为什么可能成为推理网关的瓶颈。

## 虚拟内存与内存管理

10. ★ 什么是虚拟内存？页表、TLB、缺页异常分别解决什么问题？
11. 解释大页内存的原理，以及它在 GPU 训练数据加载和 KV Cache 管理中的潜在价值。
12. 什么是内存屏障？在 Go 的并发模型和分布式存储复制协议中，内存屏障或等价语义为什么重要？
13. ★ 解释 buddy system 与 slab 分配器的原理：buddy 如何通过伙伴块的分裂与合并减少外部碎片？slab 如何在 buddy 之上减少内部碎片并缓存高频分配的对象？
14. 解释用户态内存申请路径：glibc malloc 什么时候通过 brk 扩展堆、什么时候通过 mmap 单独映射？两条路径与内核的交互方式以及内存回收行为有什么差异？

## 进程、线程与协程

15. 解释进程、线程、协程的区别，以及 Go runtime 调度器如何映射到操作系统线程。
16. 什么是 GMP 模型？Go 的调度器在高并发网络服务中相比传统线程模型有哪些优势与代价？

## I/O 模型与事件驱动

17. 解释阻塞 I/O、非阻塞 I/O、I/O 多路复用、信号驱动 I/O、异步 I/O 的区别。
18. ★ 什么是 epoll？水平触发与边缘触发的区别是什么？在 Go netpoll 中如何体现？
19. 解释 Reactor 与 Proactor 模式，并说明它们在高并发推理网关中的适用性。
20. 什么是文件描述符？文件描述符耗尽时，系统层面通常有哪些表现和排查手段？
21. 解释 Linux 中一切皆文件的设计哲学，以及它对设备、管道、socket、cgroup 抽象的影响。

## 文件系统与存储 I/O

22. ★ 什么是 page cache？它如何影响训练数据读取、模型加载和日志写入性能？
23. ★ 解释 buffered I/O 与 direct I/O 的区别，以及 O_DIRECT 在数据库和分布式存储中的取舍。
24. 什么是 fsync、fdatasync？为什么分布式存储系统不能简单依赖 fsync 来保证一致性？
25. 解释 ext4、XFS、Btrfs 的基本设计差异，以及它们对大规模小文件训练数据集的影响。
26. 什么是 inode？inode 耗尽会导致什么问题？如何排查和缓解？
27. 解释硬链接与软链接的区别，以及它们在容器镜像层中的表现形式。
28. 什么是 VFS？它如何统一不同文件系统的接口？
29. 解释 FUSE 的原理，以及它为什么可能成为训练数据流加速中的性能瓶颈。
30. ★ 什么是 io_uring？它相比 epoll + 传统 AIO 有哪些优势？适合哪些 AI Infra 场景？

## 并发与同步

31. 解释 CPU 缓存一致性协议 MESI，以及多核环境下共享数据结构的性能陷阱。
32. 什么是伪共享？如何在 Go 中通过 padding 或数据结构布局缓解？
33. 解释原子操作与锁的区别，以及 CAS 在无锁队列和分布式协调中的应用。
34. 什么是自旋锁、互斥锁、读写锁？分别适合什么竞争强度和临界区长度？
35. 解释条件变量与 channel 的语义差异，以及 Go 中何时该用 channel、何时该用 mutex。
36. 什么是死锁、活锁、饥饿？在分布式训练任务调度中如何避免？

## 网络协议与低延迟传输

37. ★ 解释 TCP 三次握手与四次挥手，以及 TIME_WAIT 过多对推理网关的影响。
38. 什么是 TCP 粘包与拆包？在自定义 RPC 协议中如何设计消息边界？
39. 解释 Nagle 算法与 TCP_NODELAY，以及它们对低延迟推理请求的影响。
40. 什么是拥塞控制？CUBIC、BBR 的基本思想差异是什么？对跨机房模型传输有什么影响？
41. 解释 HTTP/1.1、HTTP/2、HTTP/3 的关键差异，以及 gRPC 为什么常基于 HTTP/2。
42. 什么是 TLS 握手？会话复用、0-RTT、mTLS 在服务网格和推理网关中的作用是什么？

## GPU 与高性能数据通路

43. ★ 解释 RDMA 的基本原理，以及它在分布式训练 AllReduce、参数同步和存储访问中的价值。
44. 什么是 RoCE 与 InfiniBand？它们相比 TCP 在 AI 集群中的优势和运维挑战是什么？
45. ★ 解释 GPU 与 CPU 之间的数据通路：PCIe、NVLink、NVSwitch 的带宽和拓扑差异。
46. 什么是 pinned memory？为什么 GPU 训练中的数据加载常使用 pinned memory？
47. 解释 CUDA Stream 与异步拷贝，以及它们如何影响数据加载与计算重叠。
48. ★ 什么是 GPUDirect Storage？它试图解决什么问题？对训练数据流加速意味着什么？
49. 解释 SSD 的读写放大、垃圾回收、TRIM，以及它们对高吞吐数据管道的影响。
50. 什么是 RDMA over Converged Ethernet 的 PFC 与 ECN？为什么无损网络对 AI 集群重要？

## 容器隔离与资源控制

51. 解释 cgroup 与 namespace 的区别，以及它们如何共同构成容器隔离的基础。
52. 解释 cgroup v1 与 v2 的主要差异：统一层级、no-internal-process 约束、控制器委托与 PSI 压力反馈，对容器运行时和 Kubernetes 资源管理有什么影响？

## 思考与取舍题

54. 用 O_DIRECT 做备份与恢复，速度反而比 buffered I/O 更慢——列出三个候选原因并按可能性排序。
55. 估算 8 卡 H100 节点上 NVLink 总带宽与 PCIe 总带宽的量级差，这个差值如何决定 AllReduce 算法与跨机通信方案的选择？
56. 把 L3 缓存扩大 4 倍但访问延迟翻倍，对训练吞吐未必是好事——什么样的负载特征会让这笔交易亏损？
57. NUMA 绑定能降延迟，但把训练进程的内存严格绑死在单个节点上，什么场景下反而酿成事故？
58. 大页能减少 TLB miss，但请各构造一个它让缺页处理变慢、让内存碎片恶化的反例。
59. epoll 边缘触发相比水平触发省下的系统调用开销最终去了哪里？什么条件下这点节省会被读写循环的复杂度反噬？
60. 中断风暴与轮询空转分别出现在什么负载区间？两者的临界切换点由哪些因素决定？
61. 把掉电窗口从秒级压到接近零，吞吐与尾延迟会先在哪里崩掉？组提交在这笔交易里扮演什么角色？
62. 零拷贝在 TLS 网关里往往名存实亡——哪些中间层会把"零拷贝"悄悄变回两次拷贝？
63. pinned memory 让主机到显卡的拷贝更快，为什么它用多了反而可能拖累整机与其他进程？
64. 量级估算：每秒 10 万请求、每请求 20 次系统调用的推理网关，系统调用与上下文切换的开销占 CPU 的比例有多大？
65. 训练节点内存带宽已经打满，CPU 利用率却只有 30%——列三个候选原因并按可能性排序。
66. 估算把 100GB 的 checkpoint 从 NVMe 装进 8 卡 H100 的最短加载时间，瓶颈卡在哪一段链路上？
67. 把网卡中断绑定到与 GPU 同 NUMA 的核上，为什么有时反而让那个核成为瓶颈？该怎么判断该绑还是该分散？
68. 假设把 page cache 从内核里删掉，哪些系统会最先失败？分布式存储客户端为什么反而要自建缓存？
69. CPU 频率显示正常、机器负载很低，训练性能却只有标称的一半——列三个候选原因并按可能性排序。
70. 取舍辩论：跨机训练流量走 RDMA 还是 TCP？从运维代价、故障域与带宽利用率三个角度，TCP 阵营最硬的牌是什么？
71. 量级估算：一张 7GB/s 的 NVMe、一张 25GB/s 的网卡、一条 32GB/s 的 PCIe 通道，训练数据加载链路的短板在哪一块？请把三者换算到同一单位。
72. 假设把 buddy system 换成只分配固定尺寸块的分配器，哪些负载受益、哪些立刻失败？
73. 节点 free 显示还有几百 GB available，新进程却触发 OOM——列三个候选原因并按可能性排序。
