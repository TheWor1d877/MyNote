## A. S 类：独立成项

### S2 RDMA 传输臂（8–13）

> 高性能网络的唯一实战项，4 周止损。P1 主路径是 gRPC stream，RDMA 是 Transport 接口的第二个实现，永远不进主路径。Soft-RoCE 上功能可验证、性能不可采信；真值按小时租 eRDMA 校准一次。

8. ★【证据题】Soft-RoCE 的功能与性能边界：`rdma_rxe` 在哪一层模拟网卡，内核旁路、零拷贝、CPU 卸载三项各剩多少？`ibv_poll_cq` 与事件通知在软件栈上差在哪一步，为什么事件通知经常丢、轮询成为被迫选择？哪几条结论不能从 rxe 实验里取？
9. ★【工程】PD、MR、CQ、QP 在 P2P 块传输原型里各出现在哪一步？`ibv_reg_mr` 为什么算热路径开销，为什么要锁页？4KB / 256KB / 4MB 三档注册耗时你测过吗，为什么不能按需注册 4KB 小块？
10. ★【数字】⏳ Soft-RoCE、TCP、gRPC stream 三档在 4KB / 256KB / 4MB 下的 P50 与 P99 各是多少？这组数据能支撑“KV 走 RDMA 比 TCP 快 X 倍”这句话吗；不能的话，你能支撑的说法是哪一句？eRDMA 云真值校准回来的差距怎么用？
11. ★【取舍】为什么选“独立 C++ 组件 + 薄 C ABI”，不把 libibverbs 通过 cgo 链进 Go 热进程？三个原因（切换开销 2–5μs、CQ 轮询放 C 进程、Go GC 移动内存）各用什么最小实验证明？C ABI 暴露哪四个函数，复杂状态为什么留在 C++ 里？
12. ★【对标】RDMA Write 与 Send/Recv 在 P2P 拉取式场景怎么选？`ibv_reg_mr` 锁页与预注册槽位解决了什么？RoCE 的 PFC / ECN / MTU=4096 三前提怎么配合，跨子网丢包不重发会怎样？Mooncake Transfer Engine、NVIDIA NIXL、UCX 已经做了同一件事，你这一项留下的是什么？
13. ★【止损】【复用】载体怎么定：并进 P1 `experimental/`，还是独立仓库？两种情况验收标准各是什么？4 周只做到“跑通”时，讲法怎么降级成《为什么我没在主路径上 RDMA》？回写 P1 README 的那条曲线或否定结论具体写什么？

### S3 SLO 校准与回放台（14–19）

> 补 Pact 第 9、10、17 节缺的实测数据：违约概率要经过校准才算数，四类处置要在同一份历史数据上比一次。纯 CPU，独立仓库。

14. ★【取舍】为什么交付概率加校准，点值预测在什么场景下不够用？历史分位数与 Little 定律估算这两条基线各自在什么条件下够用、什么条件下失效？SLO 口径（TTFT p99、ITL p99、分副本与分模型）怎么定，违约判定按单请求还是按窗口聚合？
15. ★【正确性】右截断标签（窗口内还没跑完的请求）怎么处理？违约率低时重采样会不会改变结论，报告里怎么写清重采样前后的分布？哪些特征属于时间泄漏，你怎么保证预测时刻只用入队时可见的量？
16. ★【数字】⏳ 可靠性图、Brier、ECE 三个数怎么算，校准前后各一份？等距回归与 Platt 缩放在你的数据上差多少？分副本、分负载类型、分命中深度切片之后，校准在哪一档先失效？
17. ★【工程】漂移检测用什么统计量（PSI 还是 KL），滑窗多长、阈值取在哪？人为把到达率翻倍，告警在多长时间内触发？触发之后重校准的条件是什么，不重校准会错到什么程度？
18. ★【上难度】回放器怎么做到事件驱动：时间轴按到达与完成推进，四类动作（准入、降级、扩容、路由）的决策点各在哪，迟滞怎么设才不抖？代价表里拒绝损失、质量折损、扩容单位成本、跨域时延各怎么计量？哪类动作在哪种负载下有效，给一张对照表。
19. ★【失败】预测概率偏差 ±20% 时，策略收益还剩多少，敏感度曲线怎么画？举一个预测失败的案例，把错误归到特征、标签或漂移中的一处，并说明下一次怎么提前发现。

## B. M 类：附加臂


### M4 外部口径校验（33–35）

> 2 天量级，P2 附录题。进程内打点由 P2 主体做，这一项从进程外用 uprobe 采 token 级时间，量两套口径的偏差与探针自身开销。

33. ★【证据题】uprobe 挂在哪个文件的哪个函数上（`Scheduler.schedule` 还是 `execute_model`）？挂载点是 N3 笔记定的还是自己选的？CPU 后端与 GPU 后端两种情况各有什么坑，Python 符号解析不稳时怎么兜？
34. ★【数字】同一批请求，外部探针与进程内时间戳在排队、prefill、decode 三段上的偏差 P50 与 P99 各是多少？偏差来自时钟源（CUDA event 与 wall clock）还是插桩位置？举一条两个口径对不上的请求，拆到具体阶段。
