## 配置虚拟网络
设置子网ip为192.168.88.0
网关ip为192.168.88.2

网关IP是虚拟网络中的一个特定地址，用于路由虚拟机的网络流量。在NAT模式下，VMware会创建一个虚拟NAT设备，并为其分配一个网关IP地址（如截图中的192.168.88.2）。虚拟机通过这个网关IP地址访问外部网络。

## 配置主机名
使用：
```bash
hostnamectl set-hostname 你的主机名
```

## 配置ip地址
修改/etc/netplan/01-netcfg.yaml文件
示例：
```bash
network:
     version: 2
     ethernets:
       ens33:  # 替换为你的网络接口名称，例如 eth0 或 ens33
         dhcp4: no
         addresses:
           - 192.168.88.101/24  # 静态IP地址和子网掩码
         gateway4: 192.168.88.2  # 网关地址
         nameservers:
           addresses:
             - 192.168.88.2  # DNS服务器地址
```
修改后重启即可更新
