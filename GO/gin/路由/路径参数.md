Gin 支持两种类型的路径参数，让你可以直接从 URL 中捕获值：

- `:name `—— 匹配单个路径段。例如，/user/:name 匹配 /user/john，但不匹配 /user/ 或 /user。
- `*action` —— 匹配前缀之后的所有内容，包括斜杠。例如，`/user/:name/*action` 匹配 /user/john/send 和 /user/john/。捕获的值包含前导 /。

```go
package main

import (
  "net/http"

  "github.com/gin-gonic/gin"
)

func main() {
  router := gin.Default()

  // This handler will match /user/john but will not match /user/ or /user
  router.GET("/user/:name", func(c *gin.Context) {
    name := c.Param("name")
    c.String(http.StatusOK, "Hello %s", name)
  })

  // However, this one will match /user/john/ and also /user/john/send
  // If no other routers match /user/john, it will redirect to /user/john/
  router.GET("/user/:name/*action", func(c *gin.Context) {
    name := c.Param("name")
    action := c.Param("action")
    message := name + " is " + action
    c.String(http.StatusOK, message)
  })

  router.Run(":8080")
}
```

Gin 提供了基于 httprouter 构建的强大路由系统，用于高性能的 URL 匹配。在底层，<span style="color:rgb(221, 85, 85)">httprouter 使用基数树（也称为压缩字典树）来存储和查找路由</span>，这意味着路由匹配非常快速，每次查找零内存分配。这使得 Gin 成为最快的 Go Web 框架之一。
