## 单元测试
测试单个函数的准确性
#### 最基本的测试写法
```go
// math.go
func Add(a, b int) int {
    return a + b
}

// math_test.go
package main

import "testing"

func TestAdd(t *testing.T) {
    result := Add(2, 3)
    expected := 5
    if result != expected {
        t.Errorf("Add(2, 3) = %d; expected %d", result, expected)
    }
}
```
#### 多个子测试
```go
func TestAdd(t *testing.T) {
    t.Run("positive numbers", func(t *testing.T) {
        if got := Add(2, 3); got != 5 {
            t.Errorf("got %d, want 5", got)
        }
    })

    t.Run("negative and positive", func(t *testing.T) {
        if got := Add(-1, 1); got != 0 {
            t.Errorf("got %d, want 0", got)
        }
    })
}
```
## 表驱动测试
```go
func TestAdd(t *testing.T) {
// 创建测试表
    tests := []struct {
        name     string
        a, b     int
        expected int
    }{
        {"two positives", 2, 3, 5},
        {"positive and negative", 5, -3, 2},
        {"zero", 0, 0, 0},
    }
// 标准写法
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            if got := Add(tt.a, tt.b); got != tt.expected {
                t.Errorf("Add(%d, %d) = %d; expected %d", tt.a, tt.b, got, tt.expected)
            }
        })
    }
}
```
易扩展：加新 case 只需加一行。
避免重复代码。
测试逻辑与数据分离，清晰易读。

## 基准测试
基准测试函数以 Benchmark 开头，参数是`*testing.B`，核心是循环`b.N`次：
```go
// math.go
func Add(a, b int) int {
    return a + b
}

// math_test.go
func BenchmarkAdd(b *testing.B) {
    for i := 0; i < b.N; i++ {
        Add(2, 3)
    }
}
```
#### 测试带有状态的操作
如果一个函数依赖对象状态，那么需要再循环外面初始化
```go
type Counter struct {
    value int64
}

func (c *Counter) Inc() {
    atomic.AddInt64(&c.value, 1)
}

func BenchmarkCounterInc(b *testing.B) {
    counter := &Counter{}
    for i := 0; i < b.N; i++ {
        counter.Inc()
    }
}
```
如：测试为什么 etcd、TiKV 等系统都用自定义二进制协议！
#### 高级技巧
- 重置计时器：重置计时器：如果初始化很耗时，但不想计入 benchmark
`b.ResetTimer()`
- 并行测试：模拟多个goroutine进行访问
```go
func BenchmarkConcurrentGet(b *testing.B) {
    store := NewStore()
    b.RunParallel(func(pb *testing.PB) {
        for pb.Next() {
            store.Get("key")
        }
    })
}
```
