#面试-Go语言-复习 解释 Go 中的背压，如何用有缓冲 channel 和信号量控制并发

背压就是下游处理不过来时，把压力反向传递回上游，逼上游慢下来或拒绝——防止请求无限堆积把内存和下游压垮。
## channel
Go中采用有缓冲的channel做背压，<span style="color:rgb(221, 85, 85)">通过阻塞操作将压力还给上游</span>，上游如果发生阻塞就只能等待或者放弃 
channel的缓冲区不是越大越好，缓冲越大，背压传导越晚，系统"反应迟钝"，等到发现时已经堆爆了
channel 更适合数据传递 + 背压，缓冲区大小是固定的。

## 信号量
信号量本质是一个带计数的许可池。Go 里最简洁的实现就是带缓冲的 channel 当计数器：
```go
sem := make(chan struct{}, maxConcurrent)  // 容量 = 最大并发数
// 获取许可
sem <- struct{}{}
// 执行任务
doWork()
// 释放许可
<-sem
```
这里 sem <- struct{}{} 就是"占一个坑",满了就阻塞，阻塞就是背压：并发达到上限，新的请求进不来，压力回传。用完 <-sem 释放坑位。

信号量更适合纯粹控制并发数,不传数据，只传"许可"，而且可以支持加权。

#### 标准库
`golang.org/x/sync/semaphore` 提供了更完整的版本，支持一次申请多个权重（比如一个请求占 3 个单位的资源）、支持 context 取消。适合"不同任务资源消耗不一样"的场景。
