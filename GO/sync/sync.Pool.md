## 对象池 (Object Pool) - sync.Pool
这是 Go 标准库中最核心、最常用的“池”。

- 核心作用
缓存和复用临时的、无状态的、分配成本较高的小对象（如 []byte、strings.Builder、自定义结构体等）。
主要目标是减轻垃圾回收器（GC）。

- 关键特性
临时性：池中的对象可能会在任何时候被自动移除（例如，在每次 GC 后）。因此，它不能作为长期缓存使用。
无状态：从池中取出的对象状态是不确定的，使用前必须重置。
高性能：内部使用了 per-P（每个处理器）的本地池和全局池，避免了全局锁竞争。

```go
var buffer = sync.Pool{
	New: func() interface{} {
		fmt.Println("📦 创建新的字节切片")
		return make([]byte, 1024)
	},
}
```
池中的每个对象都是1024长度的byte切片，初始化是没有对象的
使用PUT与GET来放回与取得对象
