空接口是所有类型的超集 —— 因为它不包含任何方法，所以任何类型都自动满足它。
Go 的 空接口 interface{}（Go 1.18+ 后等价于 any）是带类型信息的安全容器。
## interface的内存结构
在 Go 中，interface{} 并非“万能容器”，而是一个包含两个指针的结构体
```go
// runtime/iface.go (伪代码)
type iface struct {
    tab  *itab   // 类型信息 + 方法表
    data unsafe.Pointer // 指向实际数据
}
```
data：指向实际存储的值（可能是栈上、堆上或直接内联的小对象）
tab（itab）：包含：
`_type`：类型的元信息（大小、对齐、哈希等）
`inter`：接口类型定义
`fun[1]`：方法指针数组（用于动态派发）
✅ 关键点：interface{} 本身不存储数据，只持有指向数据的指针和类型描述符。

## 类型转换与类型断言
特性	类型转换	类型断言
适用对象	具体类型之间	接口类型
语法	T(v)	v.(T)
失败时	编译错误	返回 false 或 panic
底层检查	编译时检查	运行时检查

## 类型 switch：多类型处理
```go
func describe(x interface{}) {
    switch v := x.(type) {
    case int:
        fmt.Println("Integer:", v)
    case string:
        fmt.Println("String:", v)
    case bool:
        fmt.Println("Boolean:", v)
    case Dog:
        fmt.Println("Dog named:", v.Name)
    default:
        fmt.Println("Unknown type")
    }
}

// 使用
describe(42)        // Integer: 42
describe("hi")      // String: hi
describe(Dog{"Max"})// Dog named: Max
```
