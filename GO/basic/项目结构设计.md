## 指针与值接受者
需要修改字段 使用指针
大对象避免拷贝 使用指针
事件接口的时候注意统一性，不能一个使用值一个用指针

## 项目分层
```text
distributed-storage-demo/
├── cmd/
│   └── storage-server/     # 主程序入口（main.go）
├── pkg/
│   ├── api/                # 对外 gRPC/HTTP 接口
│   ├── store/              # 存储引擎实现
│   └── metrics/            # Prometheus 指标
├── internal/               # 内部模块（不对外暴露）
│   └── wal/
├── go.mod
└── Makefile
```
✅ pkg/：可被外部 import 的公共库
✅ internal/：仅本项目使用，Go 编译器强制限制
internal/ Go强制其他项目import internal/下面的包，强制封装边界
