## 通信集合原语
一共8个集合原语，可以用三个维度来定位：是否带归约、结果落在哪里（一个 rank 还是所有 rank）、数据是聚拢还是打散

#### Boardcast
```text
操作前：GPU0=[7]  GPU1=[ ]  GPU2=[ ]  GPU3=[ ]
操作后：GPU0=[7]  GPU1=[7]  GPU2=[7]  GPU3=[7]
```
将 root rank 的缓冲区内容复制到 communicator 内所有 rank 的接收缓冲区
- **归约行为**：不执行归约，不产生新数值。
- **结果分布**：所有 rank，各 rank 内容相同。
- **数据流向**：复制分发，不聚拢、不拼接。
- **root 指定方式**：由 rank 索引指定，受 rank-to-device 映射影响。
- **训练用途**：初始化阶段将参数或配置从 rank 0 分发到所有 GPU。
- **推理用途**：vLLM 等框架将训练侧更新后的权重从训练进程广播至推理进程。

#### Reduce
```text
操作前：GPU0=[3]  GPU1=[5]  GPU2=[2]  GPU3=[4]
操作后：GPU0=[14] GPU1=[ ]  GPU2=[ ]  GPU3=[ ]   （sum 归约）
```
对各 rank 的输入执行归约，归约结果仅写入指定 root rank 的接收缓冲区
- **归约行为**：执行归约。
- **结果分布**：仅 root rank，其余 rank 不保留归约输出。
- **数据流向**：聚拢到一个点，归约后单点驻留。
- **训练用途**：将各 rank 的标量指标（如 loss）汇总到一个 rank 记录；也可作为 AllReduce 的拆分步骤。
- **等价关系**：Reduce + Broadcast = AllReduce。

#### AllReduce
```text
操作前：GPU0=[3]  GPU1=[5]  GPU2=[2]  GPU3=[4]
操作后：GPU0=[14] GPU1=[14] GPU2=[14] GPU3=[14]   （sum 归约）
```
对各 rank 的输入执行归约，并将相同的归约结果写入所有 rank 的接收缓冲区。
- **归约行为**：执行归约。
- **结果分布**：所有 rank，各 rank 内容相同。
- **数据流向**：归约后全 rank 驻留，不切分。
- **训练用途**：DDP 反向传播后的梯度同步，所有 GPU 获得相同的平均梯度。
- **推理用途**：张量并行中将各 GPU 计算的部分结果归约为完整层输出。
- **等价关系**：Reduce + Broadcast；ReduceScatter + AllGather。

#### Gather
```text
操作前：GPU0=[3]  GPU1=[5]  GPU2=[2]  GPU3=[4]
操作后：GPU0=[3,5,2,4]  GPU1=[ ]  GPU2=[ ]  GPU3=[ ]   （按 rank 序拼接）
```
将各 rank 的输入按 rank 索引顺序拼接，拼接结果写入指定 root rank 的接收缓冲区。
- **归约行为**：不执行归约。
- **结果分布**：仅 root rank，其余 rank 不保留拼接输出。
- **数据流向**：聚拢到一个点，按 rank 序拼接。
- **训练用途**：LLM 训练中较少单独使用，主要作为理解 AllGather 的参照。
- **关系**：Gather 是 AllGather 的单 root 版本；Scatter 是它的逆操作。

####  AllGather
```text
操作前：GPU0=[3]  GPU1=[5]  GPU2=[2]  GPU3=[4]
操作后：GPU0=[3,5,2,4]  GPU1=[3,5,2,4]  GPU2=[3,5,2,4]  GPU3=[3,5,2,4]
```
将各 rank 的输入按 rank 索引顺序拼接，并将相同的拼接结果写入所有 rank 的接收缓冲区。
- **归约行为**：不执行归约。
- **结果分布**：所有 rank，各 rank 内容相同。
- **数据流向**：聚拢后全 rank 驻留，按 rank 序拼接。
- **训练用途**：FSDP 前向传播中将分片参数重建为完整参数；张量并行与序列并行中收集分片激活或权重。
- **关系**：与 ReduceScatter 互为对偶操作。

#### Scatter
```text
操作前：GPU0=[3,5,2,4]  GPU1=[ ]  GPU2=[ ]  GPU3=[ ]
操作后：GPU0=[3]  GPU1=[5]  GPU2=[2]  GPU3=[4]   （按 rank 序切分）
```
将 root rank 的输入缓冲区按 rank 索引切分为等长块，分发至对应 rank 的接收缓冲区。
- **归约行为**：不执行归约。
- **结果分布**：所有 rank，但各 rank 数据块不同。
- **数据流向**：从一个点打散，按 rank 序切分。
- **训练用途**：LLM 训练中较少单独使用。
- **关系**：Scatter 是 Broadcast 的“按 rank 分发不同块”版本；Gather 是它的逆操作。

#### ReduceScatter
```text
操作前：
GPU0=[1,2,3,4]
GPU1=[5,6,7,8]
GPU2=[9,10,11,12]
GPU3=[13,14,15,16]

sum 归约结果：[28,32,36,40]
按 rank 切分后：
GPU0=[28]  GPU1=[32]  GPU2=[36]  GPU3=[40]
```
先对各 rank 的输入执行归约，再将归约结果按 rank 索引切分，各 rank 仅保留属于自己的那一块。
- **归约行为**：执行归约。
- **结果分布**：所有 rank，但各 rank 仅持有归约结果的一个分片。
- **数据流向**：先归约聚拢，再按 rank 切分散开。
- **训练用途**：FSDP/ZeRO 反向传播中切分梯度，降低显存占用与通信量。
- **关系**：与 AllGather 互为对偶操作；Ring AllReduce 的第一阶段即 ReduceScatter。

#### AllToAll
```text
操作前：
GPU0 发送：给GPU0=a00, 给GPU1=a01, 给GPU2=a02, 给GPU3=a03
GPU1 发送：给GPU0=a10, 给GPU1=a11, 给GPU2=a12, 给GPU3=a13
GPU2 发送：给GPU0=a20, 给GPU1=a21, 给GPU2=a22, 给GPU3=a23
GPU3 发送：给GPU0=a30, 给GPU1=a31, 给GPU2=a32, 给GPU3=a33

操作后：
GPU0 收到：a00, a10, a20, a30
GPU1 收到：a01, a11, a21, a31
GPU2 收到：a02, a12, a22, a32
GPU3 收到：a03, a13, a23, a33
```
每个 rank 向 communicator 内每一个其他 rank 发送不同的数据块，同时从每一个其他 rank 接收数据块。
- **归约行为**：不执行归约。
- **结果分布**：所有 rank，但各 rank 数据组合不同。
- **数据流向**：全交换，可视为分布式矩阵转置。
- **训练与推理用途**：MoE 专家并行中 token 的 dispatch 与 combine；序列并行中的重排。
- **与其他原语的区别**：AllReduce 是所有 rank 获得相同的归约结果；AllToAll 是各 rank 获得不同的、来自所有 rank 的数据块。
