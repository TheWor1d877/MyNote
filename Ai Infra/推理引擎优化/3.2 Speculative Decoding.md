自回归生成的根本瓶颈再与每个Token都依赖于前一个Token的输出
GPU的并行算力在Decode阶段几乎完全闲置
## Speculative Decoding的核心思想
通过小模型猜出一串Token，然后大模型一次性验证，从而将多次串行的前向压缩成一次并行的前向

流程：
```
投机流程：
  Step 1: Draft Model (8B) 快速自回归生成 5 个候选 Token (~50ms)
  Step 2: Target Model (70B) 一次性并行验证这 5 个 Token (~300ms)
  Step 3: 接受前缀，拒绝后缀，从拒绝位置继续
  总计 ~350ms，若接受 4 个 Token，则加速比 ≈ 4×
```

一旦某个位置被拒，后面所有位置作废（因为它们是建立在被拒 token 的前提上的）。然后从拒绝位置，用 target 的输出直接采样一个正确的 token，继续。

验证第二个Token的时候默认第一个Token是正确的
## 实现机制： Draft Model，并行验证
Draft Model 选型策略：

| 类型              | 代表方案             | 特点              | 接受率     | 加速比      |
| --------------- | ---------------- | --------------- | ------- | -------- |
| 独立小模型           | Llama-3-8B 配 70B | 需加载两个模型，显存翻倍    | 60%~80% | 2.0~2.5× |
| 自投机（Early Exit） | 目标模型前 N 层        | 零额外显存，分布一致性高    | 40%~60% | 1.3~1.8× |
| Medusa（多头）      | 附加预测头            | 无需额外模型，微调头即可    | 70%~85% | 2.5~3.0× |
| EAGLE（特征级）      | 预测隐藏状态           | 接受率最高，参数仅 2%~5% | 75%~90% | 3.0~4.0× |


并行注意力计算：
目标模型验证 K 个方案的候选 Token链条时，并非执行 K 次独立前向，而是构造一个树状注意力（Tree Attention）结构，一次性处理所有候选路径。
```text
候选树示例（K=3，每位置 top-2）：
         root
        /    \
      t1_a   t1_b
     /   \     \
   t2_a  t2_b  t2_c
   /       \
 t3_a     t3_b

目标模型一次前向传播，同时计算所有路径的联合概率，
然后选取最长的"全部接受"前缀。
```

树状注意力的优点是可以复用KV Cache，所有路径共享相同的前缀 KV，仅对新增的候选 Token 做增量计算，使得验证 K 个 Token 的成本与验证 1 个几乎相同（Memory-Bound 特性决定）。

## 工程实践：Medusa、EAGLE 等无额外小模型的方案
#### Medusa 多头并行加速
在目标模型的最后一层的隐藏状态上面附加多个独立的解码头，每个头用来预测未来第i个位置的Token
```text
Head_1 → 预测 t_{n+1}
Head_2 → 预测 t_{n+2}
Head_3 → 预测 t_{n+3}
```
推理时，所有头并行输出，构造候选树后通过 Tree Attention 一次性验证。额外参数量仅约主模型的 1%，无需加载独立草稿模型。

#### EAGLE： 特征级投机
EAGLE 的核心创新是将草稿从 Token 空间移到特征空间
预测倒数第二层的隐藏状态，在有大模型自己转成预测的Token
最后大模型验证这一串或者一颗树的Token

#### 其他方案
DFlash：用 Block Diffusion 替代自回归草稿，单次前向并行生成整个 Token 块，Qwen3.8-27B 上吞吐提升 2.7~3.4×
SuffixDecoding：基于后缀树缓存历史序列，Agent 场景下加速高达 5.3×
Saguaro（SSD 框架）：2026 年 3 月提出，在验证的同时预预测下一轮草稿，打破起草-验证的串行依赖，Llama-3-70B 上相对标准投机解码再快 ~2×
Draft-OPD：2026 年 EMNLP 接收，通过对策蒸馏解决离线训练与在线推理的分布错位，思考模型上实现 >5× 无损加速

## 适用场景
长序列生成：生成的 Token 越多，投机解码的累积加速效果越显著
代码补全 / RAG / 翻译：规律性强、重复性高，接受率可达 80% 以上
Agent 工作流：重复性子任务多，SuffixDecoding 等方案收益极高
