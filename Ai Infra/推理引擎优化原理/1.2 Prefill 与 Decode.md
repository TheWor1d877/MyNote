隐藏维度为 `d`，词表大小为 `V`，KV Cache 当前长度为 `T`。每层有独立的可学习参数 `Wq/Wk/Wv`，形状均为 `d x d`；LM Head 形状为 `d x V`。

## Prefill 阶段：处理用户输入的 10 个 token

1. 输入 10 个 token id，形状 `10 x 1`；Embedding 后得到 `10 x d`。
2. 进入第 1 层，用本层 `Wq/Wk/Wv` 一次性投影出 Q/K/V，形状均为 `10 x d`。10 个 token 的 Q/K/V 是批量矩阵乘法同时算出的。
3. Attention：Q 乘 K 转置得分数 `10 x 10`，加 causal mask 后 softmax 得权重 `10 x 10`，权重乘 V 得本层输出 `10 x d`。

causal mask的作用：注意力分数表示：第 i 个 token 应该从第 j 个 token 那里取多少信息，但是前面的token不能从后面取得信息

4. 每一层重复上述过程。每层算出的 K/V 存入该层 KV Cache，Prefill 结束后每层 Cache 为 `10 x d`；Q 用完即弃，不存。
5. 走完所有层后，取最后一层第 10 个位置的输出 `1 x d`，过 LM Head 得到 logits `1 x V`，softmax 后采样出**第 1 个输出 token**（总序列第 11 个 token）。
6. 此时已生成输出 1 个；KV Cache 长度为 10，只含输入 token 的 K/V；第 1 个输出 token 自身的 K/V 尚未计算。

## Decode 阶段：逐步生成剩余 4 个输出 token

每一步只输入最新 1 个 token，形状 `1 x 1`；Embedding 后为 `1 x d`。

**Decode 第 1 步（生成第 2 个输出 token）**

- 输入第 1 个输出 token，`1 x d`。
- 每层投影出 q/k/v，形状均为 `1 x d`；当前 k/v 追加进本层 Cache，Cache 从 `10 x d` 变为 `11 x d`。
- 当前 q `1 x d` 查历史 K（`11 x d` 转置为 `d x 11`），得分数 `1 x 11`；softmax 得权重 `1 x 11`；权重乘 V_cache `11 x d`，得本层输出 `1 x d`。
- 走完所有层，最后一层输出 `1 x d` 过 LM Head 得 logits `1 x V`，采样出**第 2 个输出 token**。
- 此时 Cache 长度 11；第 2 个输出 token 的 K/V 尚未计算。

**Decode 第 2 步（生成第 3 个输出 token）**

- 输入第 2 个输出 token，`1 x d`；q/k/v 均为 `1 x d`；追加后 Cache 为 `12 x d`；分数 `1 x 12`，权重 `1 x 12`，输出 `1 x d`；LM Head 得 `1 x V`，采样出**第 3 个输出 token**。
- Cache 长度 12。

**Decode 第 3 步（生成第 4 个输出 token）**

- 输入第 3 个输出 token，`1 x d`；q/k/v 均为 `1 x d`；追加后 Cache 为 `13 x d`；分数 `1 x 13`，权重 `1 x 13`，输出 `1 x d`；LM Head 得 `1 x V`，采样出**第 4 个输出 token**。
- Cache 长度 13。

**Decode 第 4 步（生成第 5 个输出 token）**

- 输入第 4 个输出 token，`1 x d`；q/k/v 均为 `1 x d`；追加后 Cache 为 `14 x d`；分数 `1 x 14`，权重 `1 x 14`，输出 `1 x d`；LM Head 得 `1 x V`，采样出**第 5 个输出 token**。
- Cache 长度 14。

生成结束。第 5 个输出 token 的 K/V 尚未计算，因为它没有被喂回模型；若继续生成第 6 个，才会把它喂回，Cache 变为 `15 x d`。

## 流程汇总

| 步骤 | 输入 | 输入形状 | 追加后 Cache 长度 | 采样出 |
|---|---|---:|---:|---|
| Prefill | 用户输入 10 token | `10 x d` | 10 | 第 1 个输出 token |
| Decode 1 | 第 1 个输出 token | `1 x d` | 11 | 第 2 个输出 token |
| Decode 2 | 第 2 个输出 token | `1 x d` | 12 | 第 3 个输出 token |
| Decode 3 | 第 3 个输出 token | `1 x d` | 13 | 第 4 个输出 token |
| Decode 4 | 第 4 个输出 token | `1 x d` | 14 | 第 5 个输出 token |

## 关键点

- **Prefill**：10 个输入 token 的 Q/K/V 一次并行算出；K/V 存入 KV Cache，Q 丢弃；最后一层最后一个位置的输出用于采样第 1 个输出 token。
- **Decode**：每步只输入最新 1 个 token，只算它的 q/k/v；q 查 Cache 中所有历史 K，加权历史 V；历史 token 的 K/V 不重算，直接从 Cache 读。
- 每个输出 token 的 K/V，是在它**下一次作为输入被喂回模型**时才计算并追加进 Cache；最后一个输出 token 的 K/V 不会被计算，除非继续生成。
- 总序列长度：10 输入 + 5 输出 = 15；最终 KV Cache 长度：14。

## Prefill 与 Decode 对比（含 Prefill 命中 KV Cache）

前提：用户输入 `L` 个 token，KV Cache 以块为单位管理，块大小记为 `B`（比如 16 个 token 一块）。命中缓存指**从头开始连续多个完整的块**与已有缓存逐 token 一致。

#### 一、三种运行模式对比

| | Prefill（未命中缓存） | Prefill（命中部分前缀缓存） | Decode |
|---|---|---|---|
| **触发场景** | 新请求，前缀完全没算过 | 新请求，开头若干完整块与已有缓存逐 token 一致 | Prefill 结束后，逐 token 生成 |
| **输入是什么** | 全部 `L` 个 prompt token | 只输入**未命中部分**的 token，长度 `L - M`（`M` 为命中的 token 数，`M` 是块大小 `B` 的整数倍） | 最新 1 个 token |
| **输入形状** | `L x d` | `(L-M) x d` | `1 x d` |
| **Q/K/V 计算范围** | 全部 `L` 个位置 | 只算未命中的 `L-M` 个位置 | 只算当前 1 个位置 |
| **Attention 范围** | 输入内部做 causal attention | 未命中部分的 Q 查 **命中的 Cache K** + 未命中部分内部的 K | 当前 q 查 Cache 里所有历史 K |
| **KV Cache 写入** | 写入全部 `L` 个位置的 K/V | 只追加未命中 `L-M` 个位置的 K/V；命中部分**直接复用已有块**，不重算 | 追加当前 token 的 K/V |
| **Cache 长度变化** | 0 → `L` | `M` → `L` | `T` → `T+1` |
| **产出** | 采样第 1 个输出 token | 采样第 1 个输出 token | 采样下一个输出 token |
| **并行性** | `L` 个位置并行 | `L-M` 个位置并行 | 1 个位置 |

#### 二、命中缓存时的关键点

**1. 命中的是“从头开始的连续完整块”**

假设块大小 `B=16`，prompt 长度 `L=40`，已有缓存覆盖前 `M=32` 个 token（2 个完整块）。则：

- 前 32 个 token 命中，**不输入模型、不重算 Q/K/V**，直接复用已有物理块；
- 只把后 8 个 token 送进模型做 Prefill，输入形状 `8 x d`；
- 这 8 个 token 的 Q 要查 **前 32 个命中块的 K** + 这 8 个 token 内部的 K；
- 这 8 个 token 的 K/V 追加进 Cache，Cache 从 32 变为 40。

**2. 命中部分不能“只算 Q 不写 K/V”**

命中块的 K/V 已经在 Cache 里，不需要重算，也不需要重新写入。只有未命中部分的 K/V 需要计算并追加。

**3. 如果分叉发生在块中间，该块不命中**

比如前 20 个 token 与缓存一致，但块大小是 16，则只有前 16 个（第 1 个完整块）命中；第 17~20 个虽然也一致，但它们所在块不完整或与缓存块不对齐，**整个块不命中**，从第 17 个 token 开始全部重算。这是块粒度带来的复用损失。

**4. 未命中部分的 attention 仍然正确**

未命中部分的第 \(i\) 个 token，它的 Q 查的是“命中前缀的 K + 未命中部分中位置 \(\le i\) 的 K”，causal mask 保证它看不到未命中部分中它后面的 token。数学上等价于整段 `L` 个 token 一次性 Prefill，结果无损。
