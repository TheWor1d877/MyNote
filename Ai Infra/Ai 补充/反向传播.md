整个过程中Loss，梯度等计算方法

1. 前向传播： 输入数据，根据参数获得输出
2. 根据输出与真实值算出loss
3. 根据loss进行反向传播
- 根据loss算出本层参数的梯度：`∂loss/∂W2  和  ∂loss/∂b2`
- 向前传播loss对上一层输出的梯度：`∂loss/∂a1`
- 当前层根据本层算出的梯度来更新参数
- 上一层根据`∂loss/∂a1`来算出本层参数的梯度

#### 举例说明
```text
输入 x
 ↓
层1：z1 = W1 · x + b1，  a1 = 激活(z1)
 ↓
层2：z2 = W2 · a1 + b2， a2 = 激活(z2) = y_pred
 ↓
loss = (y_pred - y_true)²
```
符号说明：
- W1, b1 是层1的参数
- W2, b2 是层2的参数
- a1 是层1的输出，也是层2的输入
- a2 = y_pred 是最终预测
- loss 是损失
- 前向传播方向：x → a1 → a2 → loss
- 反向传播方向：loss → a2 → a1 → x（反过来）

反向传播从 loss 开始，一层层往回走。走到某一层时，这一层要做两件事：
事情 A：算出本层参数的梯度（用于更新本层参数）
对层2来说，就是算出：
∂loss/∂W2  和  ∂loss/∂b2
这是层2自己的参数梯度，将来用来更新 W2、b2。

事情 B：算出“传给前一层”的梯度（接力棒）
对层2来说，就是算出：
∂loss/∂a1
这是loss 对层1输出 a1 的梯度。它要交给层1，因为层1需要它才能算自己的参数梯度。
这个 ∂loss/∂a1 就是“往回传播的东西”——接力棒。


为什么层1需要 ∂loss/∂a1？
层1想算自己的参数梯度 ∂loss/∂W1。但 loss 和 W1 不直接相连，路径是：
W1 → z1 → a1 → z2 → a2 → loss
∂loss/∂W1 = ∂loss/∂a1 × ∂a1/∂z1 × ∂z1/∂W1

看第一项：∂loss/∂a1。
这一项层1自己算不出来，因为它取决于层1后面发生的一切（层2、loss）。而这些东西层1“看不见”。
所以，层2在反向时必须把 ∂loss/∂a1 算好，传给层1。层1拿到它，再乘上自己内部能算的 ∂a1/∂z1 × ∂z1/∂W1，就得到了 ∂loss/∂W1。
这就是“接力棒”的意义：每一层把“loss 对我输出的梯度”传给前一层，前一层才能继续往回算。
