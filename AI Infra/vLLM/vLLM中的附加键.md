## 前缀哈希链
块的键：`hash(父块哈希, 块内 token ids, 附加键)`，与引擎前缀缓存同口径。链式结构意味着第 0 个 token 变了，后面所有块即使内容一字不差也全部失配——「中间相同」和「语义相似」都不算命中。

## 附加键的成员
#### LoRA
大模型可以挂一个小补丁，叫 LoRA 适配器，让同一个底座模型表现出不同风格/能力。比如客服 A 的适配器、客服 B 的适配器。vLLM 里实际用 lora_name 标识。
所以每个块的哈希都要带上它，从而能联合管理多个适配器的块池。

#### Cache Salt
per-request 的隔离字符串，OpenAI 兼容协议里直接暴露为 `cache_salt` 字段。**只注入第一个块**的哈希——因为哈希是链式的，首块分叉就足以让整条链分叉。

#### 多模态哈希
图像、音频这类非离散 token 输入的指纹。做法是对覆盖到多模态输入的每个块，追加 `(identifier, offset - start_token_idx)`：identifier 是内容指纹，偏移量保证「同一张图出现在不同位置」的块能被区分开。
