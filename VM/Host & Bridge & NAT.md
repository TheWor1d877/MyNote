好的，直接上三张拓扑图，分别对应 **Host**、**Bridge**、**NAT** 三种模式下的 IP 样子。

## 图1：Host 网络模式（共享宿主机网络栈）

```text
                    外网 (Internet)
                           │
                    ┌──────┴──────┐
                    │  路由器      │
                    │ 192.168.1.1 │
                    └──────┬──────┘
                           │
                    ┌──────┴──────┐
                    │   宿主机     │
                    │ 192.168.1.100│  ← 物理网卡 eth0
                    └──────┬──────┘
                           │
                    ┌──────┴──────┐
                    │   容器/Pod   │
                    │ 192.168.1.101│  ← 和宿主机同网段，无隔离
                    └─────────────┘

特点：容器IP = 局域网真实IP，外面设备能直接访问
```

---

## 图2：Bridge 网络模式（纯虚拟交换机，无 NAT）

```text
                    外网 (Internet)
                           │
                    ┌──────┴──────┐
                    │  路由器      │
                    │ 192.168.1.1 │
                    └──────┬──────┘
                           │
                    ┌──────┴──────┐
                    │   宿主机     │
                    │ 192.168.1.100│  ← 物理网卡
                    └──────┬──────┘
                           │
                    ┌──────┴──────┐
                    │ Linux Bridge│
                    │  10.0.0.1   │  ← 虚拟交换机 IP
                    └──┬──────┬───┘
                       │      │
                 ┌─────┴──┐ ┌─┴─────┐
                 │容器 A  │ │容器 B │
                 │10.0.0.2│ │10.0.0.3│  ← 独立私有网段
                 └────────┘ └────────┘

特点：容器IP是独立私有网段(10.0.0.x)，和宿主机(192.168.1.x)不同段
     局域网其他设备无法直接访问容器
```

---

## 图3：NAT 网络模式（Bridge + 地址伪装）

```text
                    外网 (Internet)
                           │
                    ┌──────┴──────┐
                    │  路由器      │
                    │ 192.168.1.1 │
                    └──────┬──────┘
                           │
                    ┌──────┴──────────────────────┐
                    │         宿主机               │
                    │  物理网卡: 192.168.1.100     │
                    │                             │
                    │  ┌────────────────────────┐ │
                    │  │   NAT 规则 (伪装)       │ │
                    │  │  出站: 172.17.x.x → 192.168.1.100 │
                    │  │  入站: 端口映射回来      │ │
                    │  └───────────┬────────────┘ │
                    │              │               │
                    │       ┌──────┴──────┐        │
                    │       │ Linux Bridge│        │
                    │       │  172.17.0.1 │        │  ← Bridge IP
                    │       └──┬──────┬───┘        │
                    │          │      │            │
                    │     ┌────┴──┐ ┌─┴────┐       │
                    │     │容器 A │ │容器 B│       │
                    │     │172.17.0.2│172.17.0.3│  ← 容器私有 IP
                    │     └────────┘ └───────┘       │
                    └────────────────────────────────┘

特点：容器用私有网段(172.17.0.x)，出外网时源IP被伪装成宿主机IP(192.168.1.100)
     局域网其他设备依然无法直接访问容器IP（除非配端口转发）
```

---

## 三图对比总结

| 模式 | 容器IP示例 | 宿主机IP示例 | 外网看来容器是 |
|:---|:---|:---|:---|
| **Host** | `192.168.1.101` | `192.168.1.100` | 独立设备（同网段） |
| **Bridge** | `10.0.0.2` | `192.168.1.100` | 不存在（无法出网） |
| **NAT** | `172.17.0.2` | `192.168.1.100` | 宿主机自己（伪装） |

**记住**：看容器IP和宿主机IP是否同一个网段——同段是 Host，不同段是 Bridge/NAT；再看出网后源IP是否改变——改变是 NAT，不改变是纯 Bridge（但纯 Bridge 通常要配路由才能出网）。
