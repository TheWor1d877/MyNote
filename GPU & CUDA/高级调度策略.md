## Gang Scheduling（帮派调度）
Gang Scheduling 的核心思想：把一组 Pod 当作一个调度单元（PodGroup），要么全部调度成功，要么一个都不调度。

Volcano 是一个 Kubernetes 原生的批处理调度系统，专门为 AI 训练、大数据、HPC（高性能计算）等场景设计，可以理解为 Kubernetes 默认调度器 kube-scheduler 的“增强版”。

它解决什么问题？
Kubernetes 默认调度器擅长处理微服务这类“单个 Pod 独立运行”的场景。但 AI 训练任务不一样，它们通常是一组 Pod 需要协同工作（比如一个分布式的 PyTorch 训练任务，有 parameter server 和多个 worker）。如果默认调度器“来一个 Pod 就调度一个”，可能会发生：
死锁：10 个 worker 中只有 9 个被调度成功，剩下的 1 个因为资源不足一直等待。而已经占着 GPU 的 9 个 worker 也在等第 10 个，导致整个任务卡死，资源白白浪费。Volcano 就是为了解决这类问题而生的。

Volcano的核心能力就是帮派调度，它的逻辑就是“All or nothing”：Volcano 会检查一个任务的所有 Pod 是否都能满足资源需求。只有当所有 Pod 或至少达到 minAvailable 数量的 Pod 都能被调度时，它才会一次性把它们全部调度下去。否则，一个都不调度，让它们继续排队等资源。

#### 创建Gang Scheduling Job
```yaml
apiVersion: batch.volcano.sh/v1alpha1
kind: Job
metadata:
  name: llm-training-gang
spec:
  schedulerName: volcano       # 指定 Volcano 调度器
  minAvailable: 8              # 至少 8 个 Pod 同时就绪才启动
  tasks:
  - name: worker
    replicas: 8
    template:
      spec:
        containers:
        - name: pytorch
          image: pytorch-training:latest
          resources:
            limits:
              nvidia.com/gpu: 2   # 每个 Worker 2 张卡
```
你可以设置 minAvailable < replicas，比如 minAvailable=6, replicas=8，允许部分冗余启动。

## Binpacking（装箱策略）
K8s 默认调度器是 Spread 策略——优先把 Pod 分散到空闲节点，避免单节点过载。但这会导致资源碎片化
```text
集群有 3 个节点，每个节点 8 张 GPU

默认 Spread 调度：
Node1: 2 张 GPU 已用（6 张空闲）
Node2: 2 张 GPU 已用（6 张空闲）
Node3: 2 张 GPU 已用（6 张空闲）

结果：每个节点都有碎片，无法调度需要 7 张 GPU 的大任务
```

Binpacking打分原理：
Volcano 对每个节点打分，资源利用率越高，得分越高：
```text
单资源得分公式：
CPU.score = CPU.weight × (request + used) / allocatable

节点总得分：
binpack.weight × (CPU.score + Memory.score + GPU.score) / (CPU.weight + Memory.weight + GPU.weight) × 100
```
Pod优先调度到得分高的节点上面去

Volcano 安装后 Binpacking 默认生效，但你可以自定义权重：
```bash
# 编辑 Volcano Scheduler ConfigMap
kubectl edit cm volcano-scheduler-configmap -n volcano-system
```

## Queue 队列管理（多租户隔离）
在多团队共用集群时，Volcano 的 Queue 机制实现资源隔离：
```YAML
apiVersion: scheduling.volcano.sh/v1beta1
kind: Queue
metadata:
  name: ai-research-queue
spec:
  weight: 5                        # 队列权重（越高优先级越高）
  reclaimable: true                # 允许被抢占
  capability:                      # 资源配额
    cpu: 1000
    memory: 4096Gi
    nvidia.com/gpu: 128
```
可以将Job提交到指定的队列
```bash
spec:
  schedulerName: volcano
  queue: ai-research-queue
  minAvailable: 8
```
