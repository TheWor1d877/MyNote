## 广播变量
- 本地Python集合列表都是交给iDriver来管理的
- 一个Executor是一个进程，内部有若干个线程(分区)
- 如果分区需要Driver的内容，Driver会序列化相关内容然后发给分区

但是同一个进程之间的线程的资源是共享的 ，这样在同一个Executor中造成了资源浪费

所以，将向Driver要的资源设置成共享变量，这样减少IO提高性能


```python
# 将list设为广播变量
broadcast = sc.broadcast(the_list)
# 使用广播变量
value = broadcast.value
```
这样spark就会留意这个变量，减少网络IO


## 累加器
分布式计算中的累加问题
![[Attachments/Pasted image 20250829135229.png]]
分布式计算中的分区对变量的修改不会影响到Driver的变量

我们需要使用一种累加器，将分区与Driver双向同步

```python
acmlt = sc.accumulator(0)
```
使用accumulator修饰的变量，所有分区内部进行的操作都会同步给Driver
