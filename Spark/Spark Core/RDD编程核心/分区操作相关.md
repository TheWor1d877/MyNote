## mapPartitions
map是计算一次发送一次
mapPartitions是一次计算整个分区的，发送整个分区的
传递的是一个迭代器对象
```python
def process(iter):
	result = list()
	for i in iter:
		result.append(i*10)
	return result
	
print(rdd.mapPartitions(process).collect())
```


## foreachPartition
类似与mapPartitions，还是没有返回值
- 不像map一样惰性求值

## partitionBy
对RDD进行自定义分区操作
```python
rdd.partitionBy(参数1，参数2)
```
参数1：重新分区之后有几个分区
参数2： 自定义分区规则
默认规则：Hash

- 如果是kv型传参默认是key(因为只能传入一个参数)

## repartition
```python
rdd.repartition(N)
```
- 建议只减少分区
- 一般；来说除了全局排序的代码设置成一个分区，其他的分区代码我们不加理会
增加分区：
- 影响内存迭代的并行管道数(影响并行计算)
- 极大可能造成shuffle(重新分配，按照抽样的方式划分临界点)
