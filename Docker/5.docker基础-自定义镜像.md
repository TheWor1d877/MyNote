2. 安装jre并且配置环境变量
3. 拷贝jar包
4. 运行jar包

构建一个java镜像的步骤：
1. 准备一个linux运行环境
2. 安装jre包，并且配置环境变量
3. 拷贝jar包
4. 编写运行脚本
这样就构建了一个java应用

## Dockerfile
Dockerfile是一个文本文件，包含一些指令
用指令说明怎么来构建镜像

| 指令         | 说明                           | 示例  |
| ---------- | ---------------------------- | --- |
| FROM       | 指定基础镜像                       |     |
| ENV        | 设置环境变量                       |     |
| COPY       | 拷贝本地文件到镜像的指定目录               |     |
| RUN        | 执行Linux的Shell命令，一般是安装的命令     |     |
| EXPOSE     | 指定容器运行的时候暴漏的端口（使用者还是需要手动做映射） |     |
| ENTRYPOINT | 镜像中应用的启动命令，启动的时候调用           |     |

## 实操：使用Dockerfile构建镜像
创建dockerfile文件
```dockerfile
# 使用官方的 Ubuntu 基础镜像
FROM ubuntu:latest
# 设置工作目录
WORKDIR /app
# 将 1.tar.gz 文件复制到容器的工作目录中
COPY 1.tar.gz /app/
# 解压 1.tar.gz 文件
RUN tar -xzf 1.tar.gz
# 清理原始压缩包以减小镜像体积
RUN rm -f 1.tar.gz
# 确保脚本具有可执行权限
RUN chmod +x /app/run.sh
# 指定容器启动时运行的入口点
ENTRYPOINT ["/app/run.sh"]
```
- 构建镜像
`docker build -f my_dockerfile -t my-ubuntu-image .`
-f 表示dockerfile文件名，默认是当前目录下的Dockerfile文件
-t 表示镜像的名称
最后的点是镜像文件所在的目录下
