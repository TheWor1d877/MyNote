## eBPF 介绍

eBPF 是运行在 Linux 内核中的安全虚拟机(可编程沙箱)。

eBPF 允许你在不重启内核、修改源码的情况下，在用户态下往内核里动态注入一小段程序，去监听或修改内核的行为。

即使程序崩溃，也不会导致内核崩溃，eBPF 程序执行出错时（比如访问越界），只会导致该程序被停止，并返回一个错误码，内核本身稳定运行。

## bpftrace 原理

bpftrace 脚本经过 LLVM IR 翻译成 eBPF 字节码，也就是 eBPF 虚拟机的指令集。  
用户态调用 `bpf()` 系统调用把字节码交给内核。  
字节码进入内核验证器，检查通过后被 JIT 编译成机器码。  
bpftrace 把程序挂载到 tracepoint 等钩子上。事件触发时，内核在当前进程的内核上下文里执行 JIT 后的机器码。  
执行结果写进 map 或 ringbuf，用户态的 bpftrace 再周期性地读出来处理。

JIT：程序先以某种中间形式存在，等到运行时再根据当前环境或热点代码动态编译成机器码并执行。

## C 语言路径
用受限 C 编写 eBPF 程序，经 Clang/LLVM 编译成 eBPF 字节码。  
用户态加载器用 libbpf 负责加载、attach、读取 map 或 ringbuf。  
相比 bpftrace，C 路径控制更细：可以显式管理 per-CPU map、ringbuf、配对表清理路径，也方便测量探针开销。适合正式工具集，不只是快速验证。
