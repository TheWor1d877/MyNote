eth 和 veth 是 Linux 网络中的两种虚拟/物理网络接口，核心区别在于：eth 通常是物理网卡（或对物理网卡的命名），而 veth 是成对出现的虚拟网卡，专门用于连接不同的网络命名空间或虚拟网络设备。
## eth
eth 一般指以太网接口，最常见的是物理网卡在系统中的命名，比如 eth0、eth1。它是真实硬件（网卡芯片）在操作系统里的抽象，负责收发实际网络数据包。

但是在较新的 Linux 发行版中，网卡命名改成了基于固件/拓扑的可预测名称，比如 enp3s0、ens33、eno1 等，eth0 这种名字反而不一定出现。

## veth
veth 是 virtual Ethernet 的缩写，它总是成对出现，像一根虚拟网线连接两端。你在一端发送数据，另一端就会收到。
典型用途： 容器网络，网络命名空间，隧道

## 容器之间的流量
在 Docker 默认网络里，所有容器都接在同一个 Linux bridge（docker0）上。当容器 A 要发数据给容器 B 时，数据帧的路径是：

```text
容器内 eth0  <— veth pair —>  宿主机 vethxxx  <——>  网桥 docker0  <——>  物理网卡 eth0
```
容器里看到的 eth0，其实是一个 veth 的一端
宿主机上看到的是这对 veth 的另一端（名字类似 veth1a2b3c）

所以 eth 和 veth 不是对立概念：eth 是“以太网接口”的泛称，veth 是一种虚拟以太网接口。容器里的 eth0 从命名上看是 eth，从实现上看是 veth。
