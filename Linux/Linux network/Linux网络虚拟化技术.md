##  veth（Virtual Ethernet Pair）—— 虚拟网线
veth 设备总是成对出现，可以把它想象成一根虚拟的网线，两端各有一个网卡接口。数据从一端进去，会从另一端出来，就像一根真实的交叉网线连接了两个网卡。

veth 就像一根虚拟网线，把两个网络命名空间"物理上"连了起来。

## Bridge（网桥）—— 虚拟交换机
基本概念
Linux Bridge 是一个二层（数据链路层）设备，功能上等同于一个虚拟交换机。它可以把多个网络接口（包括物理网卡、veth、其他虚拟接口）连接在一起，让这些接口处于同一个广播域（同一个子网）中，实现它们之间的二层互通。

工作原理
Bridge 维护一张 MAC 地址表，记录每个 MAC 地址从哪个端口学到
收到数据帧后，根据目标 MAC 查表转发：
命中 → 从对应端口转发出去
未命中 → 向除来源端口外的所有端口泛洪（flooding）
支持 STP（生成树协议）防止环路

## Routing（路由）—— 三层转发
基本概念
路由是三层（网络层）的功能，负责决定 IP 数据包从源到目的的路径。Linux 内核通过路由表来做出转发决策。

路由表核心概念
目的网络（Destination）：目标 IP 所在的网段
网关（Gateway）：下一跳的 IP 地址
子网掩码（Genmask）：决定目的网络的范围
出接口（Iface）：从哪个网卡发出
## 总结
| 组件 | 工作层次 | 核心作用 | 类比 |
|------|---------|---------|------|
| veth | 二层 | 连接两个网络命名空间 | 虚拟网线 |
| bridge | 二层 | 连接多个接口，实现同网段互通 | 虚拟交换机 |
| routing | 三层 | 决定 IP 包的转发路径 | 虚拟路由器 |
