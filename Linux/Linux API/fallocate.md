fallocate 是 Linux 系统中的一个命令，用来快速预留（或释放）磁盘空间给某个文件。它最大的特点是：创建一个非常大的文件（比如 100GB）几乎不花时间——可能只要几毫秒！


“fallocate 只需修改文件系统的 inode 和块位图，瞬间完成（毫秒级），即使创建 100GB 文件也几乎不耗时。”

- 当运行：
```bash
fallocate -l 100G bigfile.txt
```

它不会真的往磁盘里写 100GB 的数据（比如填满 0 或其他内容），而是：
1. 告诉文件系统：“我要一个 100GB 的文件！”
2. 文件系统立刻在块位图中标记出 100GB 的连续（或非连续）磁盘块为‘已占用’；
3. 更新这个文件的 inode，把“文件大小 = 100GB”和“这些块属于我”记录进去；
整个过程只是改了两个“账本”（inode + 块位图），没有实际搬运任何数据，所以速度极快——就像你在银行预约了 100 万额度，但还没真正取出现金一样。
