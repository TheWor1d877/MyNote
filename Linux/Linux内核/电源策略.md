## EPP
EPP 是 AMD Zen 4+ 内置的"硬件级电源偏好值

- 三层结构
```text
┌─────────────────────────────────────────────────┐
│  Layer 1: CPU 硬件指令（CPPC2 协议）               │
│  CPU 本身有一个 0~255 的偏好寄存器                  │
│  0 = 最省电，255 = 最性能                         │
└──────────────────┬──────────────────────────────┘
                   │ amd-pstate-epp 驱动做了映射
┌──────────────────▼──────────────────────────────┐
│  Layer 2: EPP Preference（你现在改的就是这个）      │ 
│  Linux 把 0~255 映射成 5 个字符串：                │
│  power      (~0)        最省电                   │
│  power_performance (~64)                        │
│  balance_power    (~96)                         │
│  balance_performance (~128)  ← 你现在的设置       │
│  performance      (~255)  最性能                 │
└──────────────────┬──────────────────────────────┘
                   │ 这个值喂给 governor，影响升降频斜率
┌──────────────────▼──────────────────────────────┐
│  Layer 3: Governor（调度算法）                    │
│  powersave / performance / schedutil            │
│  你现在是 powersave                              │
└─────────────────────────────────────────────────┘
```

Governor 决定的是"调频策略，目前应该升频还是降频"（算法层)
EPP 决定的是"频率更愿意跑高还是跑低"（偏好层）

governor=powersave（算法很保守） + EPP=balance_performance（偏好偏性能）
