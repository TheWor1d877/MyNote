Linux内核模块可以包含两类代码：
内核核心代码（vmlinuz）：编译时静态链接进内核，永远常驻内存，无法卸载。比如：进程调度、内存管理、系统调用入口等。
内核模块（.ko 文件）：可按需加载/卸载，用来扩展内核功能。比如：硬件驱动、文件系统驱动（ext4/overlay）、网络防火墙（netfilter）等。

很多核心功能是静态编译进内核的，不会出现在 lsmod 里。
但绝大多数驱动和可裁切功能都以模块形式存在，所以模块确实是 Linux 内核可动态扩展的重要组成部分。
一句话：没有模块，内核也能跑（只是很残疾）；有了模块，内核才变成完整强大的操作系统。

使用`lsmod`查看linux中的内核模块
Used by 列：依赖关系与引用计数,它告诉你：
- 谁在使用这个模块？
- 为什么卸载不掉某个模块？
Size 列：模块大小（内存占用）
不是磁盘文件大小（.ko 文件），而是加载进内核后的内存占用（按页对齐）。
可以帮你发现哪些模块占用内存较多（虽然一般不大，几 KB 到几 MB）。

使用`modinfo`查看模块具体详细信息

树行查看模块依赖：
```bash
lsmod | awk '{print $1, $3}' | column -t
```
